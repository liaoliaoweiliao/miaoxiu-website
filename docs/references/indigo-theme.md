# 公共靛蓝背景与导航

2026-10-23，依用户“背景偏暗、底纹偏浅、导航和页脚需更精美且有古典苗绣文化味”及追加的“再蓝一些、不暗不泛白、绣纹浮于布面、随滚动变化、标题印章放大、栏目点击无框、配色挑战不被页脚遮挡”要求，在嘉玲分支 `df53e3d` 基础上继续调整。当前说明以本轮源码为准，前次方案的实况见工程记忆历史日志。

- 原 PNG 及其 `miao-embroidery-background-v1.md` 原封保留为已有未提交素材。本轮仅提交浏览器使用的 [indigo-embroidery.webp](../../public/assets/common/indigo-embroidery.webp)：Pillow WebP，quality=83、method=6；保持1672 × 941分辨率，317436字节，体积比PNG减少约90%。没有重绘、改变构图或修改内容图片。

## 层级与样式

`SiteBackground.jsx` 是五页共享的固定背景。`page-background.css` 集中定义靛蓝 `#245B85`、提亮色 `#2D6B95`、深色 `#1C4D76`、表面色与暖金变量。独立布纹层0.055，花鸟层默认0.90，装饰开关后1.00，手机乘0.90；展览几何边绣0.40/0.55。使用 lighten 混合取代会泛白的 screen，增强装饰素材的彩色针线，避免原暗底压色。滤镜及混合仅作用独立装饰层，内容不透明度、图片色彩、地图及服饰素材不变。

两侧分别取原图左右边缘，`background-size: auto 100%` 保持比例，向中央渐隐，不平铺也不沿长页面拉伸。固定背景上下各多80px，通过页面滚动进度使两侧分别向上/下移动最多65px；新增小纹样沿针脚串联，分别移动最多260/280px并逐渐显现。一个被动滚动监听用 requestAnimationFrame 合并更新 CSS 变量，ResizeObserver 在页面长度变化后重新计算；卸载时清理监听、观察与待执行帧。无定时器、拼接图或整页重新渲染。减少动态效果偏好下进度为0且纹样不移动。作品展览沿用透明主背景和少量几何绣边，卡片、弹窗保持原有行为。

导航为实底靛蓝渐变，品牌标题桌面30–38px，平板20–25px，手机18–25px；朱红原图印章增至标题字号的1.55倍。宋体栏目配回旋双层绣线、赭红菱结和四种线饰：首页蝴蝶、探源水涡、体验花朵、展览星形。默认线饰可见，当前栏目仅以暖金与纹样强调，移除点击/选中的角框和淡色底框；保留 :focus-visible 键盘焦点。手机菜单横向排列文字与线饰，搜索和装饰开关保留。

页脚以同色系蓝色织物渐变承托，顶部几何绣带、中央蝴蝶线章、“一针一线 · 生生不息”与苗绣题字构成收尾，两侧复用彩色花鸟素材。所有五页与来源入口可点击，窄屏允许链接换行。探源 main 底部增加48–76px内边距，让配色挑战按钮及其轮廓完整显示，按钮激活文案换行时也由正常文档流排开页脚。

`EmbroideryOrnament.jsx` 和 `embroidered-band.svg` 是本轮在代码中绘制的线饰，参考本站已有蝴蝶、花朵、水涡和星形主题，为当代装饰设计，不宣称复原具体传统纹样。未新增位图、第三方依赖或在线字体。导航和页脚样式集中在 `embroidered-theme.css`，继续从唯一 `index.css` 入口加载。
