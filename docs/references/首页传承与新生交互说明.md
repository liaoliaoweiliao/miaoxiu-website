# 首页“传承与新生”交互与素材核对

2026-10-26按用户要求，在原横向长卷上表达技艺延续和日常应用。标题仍为“传承与新生”，不采用此前已撤销的并排讲解／应用卡片布局。

## 素材与可说明的变化

使用既有 `public/assets/home/heritage-long-panorama-wide.webp`（2172 × 724），保留绣娘、针线、苗寨山水、长绣布、花卉与蝶形纹样、右侧本子／布袋等作品。小鸟继续使用 `bird-flap-clean.png`，只承担引导作用。本轮不生成或替换画面纹样。

逐处查看原图后，选取绣带与前方本子下部共有的红色花卉、枝叶边饰作对照：绣带的花卉较大、连续铺陈；本子将花卉缩小、排列为细窄的斜向封面边饰。这里说明的是画面中可辨认的花卉组合、相对大小和排列变化，不宣称某个完整纹样单元完全相同，也不把这张插画作为实物产品制作来源的证据。

末段两张细节均由同一原图直接裁切，左图 `viewBox="1630 410 130 94"`，右图 `viewBox="2025 465 120 83"`；没有把绣布图案复制到封面。封面高亮四边形位于原图 `(2035,456) / (2147,494) / (2144,532) / (2030,493)`，用来定位已有的边饰。

## 三段行为

1. 指尖传承：初始小鸟停在指尖上方，手部、针线及附近绣布的原图局部以23%的亮度增幅缓慢亮起。配文“一针一线之间，技艺在指尖延续。”
2. 绣纹延展：点击小鸟后，6.5秒内沿原绣布向右飞行，七处原花卉按经过顺序依次轻亮。配文“沿着绣布，看看传统纹样如何延伸出新的设计。”
3. 走进日常：再次点击后，1.8秒移动至右侧作品旁，定位封面边饰并显示上述两处细节。配文“花卉纹样从绣带的连续铺陈，变为本子封面的细窄边饰。”画面停留，直到用户点击小鸟重看。

山水建筑覆盖低透明靛蓝渐变，保持层次；小鸟缩小，提示避开手部和对照图。键盘和向左轻扫共用同一推进函数，动画中拦截重复推进，离开首页取消待执行动画。减少动态效果时静态呈现状态，不进行平移或局部循环动画。

实现入口为 `src/features/home/HeritageJourney.jsx` 和 `src/styles/home.css`。相关自动验证为 `tests/e2e/heritage.spec.js`、`site.spec.js` 和 `responsive.spec.js`；本轮实际验证与环境见工程记忆2026-10-26日志。
