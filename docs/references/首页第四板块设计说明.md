# 首页第四板块：当代应用与传承

2026-10-25，按用户“第四板块不知道在讲什么，交互周围空荡荡”的反馈调整。用户提供的 `F:/ai专题网站栏目设计结构(1)(2).docx` 将这一板块定位为“现代化应用（传承）／苗绣当代应用与传承展示”。附件作为内容参考；本次范围为首页第四板块。

## 内容与布局

标题改为“让苗绣，走进今天的生活”，用“一枚鸟纹如何从绣布走向日常”说明观看目的。三步旅程依次为“看见纹样—走近手艺—融入日常”，对应原有小鸟从绣布到指尖、再到笔记本的路径。

桌面采用长卷与讲解并排的布局；手机采用长卷在上、讲解在下。讲解随到达的阶段更新，包含当前主题、观察提示和继续按钮。按钮与画中小鸟共用 `advance`，动画期间均禁用；原有键盘回车／空格、向左轻扫、减少动态效果偏好、尺寸变化及卸载清理保留。

长卷下方补充服饰穿搭、随身配饰、生活文创三类应用灵感，并明确标注“设计示意”。图片复用已有 `home/fashion.webp` 和 `home/heritage-long-panorama-wide.webp`，通过 CSS 对准外套、手袋和笔记本取景。它们不代表具名品牌、实际销售商品或经核实的商业案例。

继续使用共享靛蓝表面变量；标题区与应用区用完整底色保障文字可读性。长卷保留边缘渐隐，移除旧的满屏宽度覆盖，避免新版并排布局被公共响应式样式拉伸。

## 实现入口

- `src/features/home/HeritageJourney.jsx`：原动画与新增讲解、阶段提示、继续按钮。
- `src/data/heritageJourney.js`：三阶段文案及三类应用灵感。
- `src/styles/home.css`：板块布局、图片取景与页面专属断点。
- `src/styles/responsive.css`：保留小鸟提示在画面内的横向限制，删除旧长卷满屏宽度和高度规则。
- `tests/e2e/site.spec.js`：验证标题、应用数量、按钮／小鸟／键盘混合操作和阶段讲解同步。
