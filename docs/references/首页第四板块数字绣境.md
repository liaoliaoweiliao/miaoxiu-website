# 首页第四板块 · 数字绣境

2026-10-26，用户提供星幻Annie的抖音作品链接，要求首页第四板块设计成视频中的效果。

## 参考与实现边界

- 用户链接：[抖音作品](https://v.douyin.com/q5S-PlumEqk/)，重定向视频ID为7529355984801926457。
- 通过作者发布的同名作品实际观看：[星幻实验室｜Annie《AI非遗造物：纹样刺绣的量子纠缠态？产品设计猜想》](https://m.manamana.net/video/detail/2765049)，页面标注2025-07-21，视频约35秒。
- 观察到的视觉是暗背景中的紫青色立体绣衣／披肩，粒子、细丝、织物在解构与聚合之间流动。参考其视觉方向与交互思路，没有将视频、截图、声音或作者的3D模型作为网站素材。
- 当前为Agent在本轮授权范围内设计的原创程序化数字艺术：披肩状开放曲面、花瓣与菱形绣纹、紫青粉配色。不是文物三维扫描、特定苗族支系服饰的精确复原，也没有调用AI生成接口或实际量子模拟。

## 页面与交互

`HomePage.jsx`第四板块使用`HeritageRebirth.jsx`；默认“数字绣境”，切换“绣线长卷”挂载原`HeritageJourney.jsx`，原小鸟三段飞行、键盘、轻扫及重返起点保留。

数字绣境采用本地WebGL着色器和54,481个粒子，透明织物面、细丝与光点共同构成绣衣。拖动或方向键旋转，Home键恢复手动视角；滑块控制0–100%聚散，主按钮在成衣和游离状态间切换；提供三种配色、暂停／继续及重置。重置恢复初始配色、聚散、视角和动态。

纵向触摸保留页面滚动，横向拖动旋转；Ctrl浏览器缩放不拦截。减少动态偏好下停止自动旋转／波动且直接切换聚散；暂停后仍可手动操作。可视区之外与隐藏页面停止绘制，组件卸载时释放缓冲、着色器、观察器与动画帧。WebGL缺失、编译失败或上下文丢失时显示本地SVG静态绣衣并禁用3D控件；上下文恢复后重新初始化。静态模式可继续进入长卷。

无新增依赖、在线资源或视频播放要求。数据在`src/data/heritageRebirth.js`，渲染在`src/features/home/embroideryScene.js`，样式在`src/styles/heritage-rebirth.css`。既有来源页的两项素材清单按原要求保留。

## 验证入口

构建后运行`npm run test:e2e -- tests/e2e/heritage-rebirth.spec.js`检查聚散／旋转／配色／暂停／重置、真实触摸事件、320–1440px控件、无WebGL、上下文丢失／恢复、动态与减少动态偏好。全站回归使用`npm run test:e2e`；原小鸟专项先点击“绣线长卷”。实际结果和交付背景见[本轮工作日志](../../wiki_memory/日志/UI修改/2026-10-26-首页数字绣境粒子绣衣.md)。
