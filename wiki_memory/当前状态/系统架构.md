# 系统架构

## 模块职责与边界

App管理五路hash导航、受控搜索、装饰主题及全局图片欣赏；Header管理手机菜单和窄屏搜索。公共组件在components，数据在data，页面样式按模块组织；main.jsx在index.css后加载embroidered-theme.css，统一共享花鸟背景及导航针脚。响应式规则由index.css末尾的responsive.css加载。

2026-10-22再次合并experience/dc8a5f8：其LookViewer及ImageLightbox与main/a607580一致，包含Ctrl/Meta原生浏览器缩放和ResizeObserver图片边界约束。该分支新增的experience-responsive.css是从main提取的规则；集成仍使用responsive.css中的完整规则，避免重复导入。该独立CSS仅保留于experience历史，当前源码没有该文件，历史同步日志中的路径按当时分支理解。

首页嵌入AtlasPage，distribution.js保存三个导览分区、20个县级地点，atlasGeography.js保存简化地理轮廓；distributionModel管理分区/省份筛选、选中、热力与会话足迹。七项国家级档案另由atlas.js关联统计。地图仅展示核心看板，原服饰图区/探源跳转/完整档案折叠区已移除，照片与来源仍保留。HeritageJourney使用全景长卷、透明小鸟、三段交互与跟随提示；上下渐隐由home.css处理。

探源采用StoryBook动画入口和StoryReader文字阅读；StitchExplorer/stitchGeometry绘制六种动态针法；ColorLab按选择顺序将1–3色映射到三层蒙版，最多三色，支持纹样切换和重置。故事书与图案素材来自用户提供的22.43.zip，迁入说明在docs/references/探源页22.43素材说明.md。

Experience的reducer与持久化集中在features/experience，保留随机寻纹、三主题永久解锁、男女36套服饰与观看器/PNG导出。GalleryPage通过ResizeObserver和滚动事件测量18处针结、生成SVG绣线路径并逐件显现，减少动效时完整展示；1100px以下单列、760px以下图文纵排，18张图保持等大的正方形。图库详情复用ImageLightbox，最新展览标题、针结和字号以gallery分支实现为准。

## 数据流与依赖

无后端或账户服务；React props/hooks/reducer组织交互，不使用HTML字符串替换页面。衣橱使用localStorage的miao-wardrobe-v4，兼容旧v3整套/v2发现数据，优先抽取未拥有服饰，男女穿戴分别保存。搜索请求有序号，相同关键词可重复触发。地图足迹仅在页面会话保存，刷新重置。

assetUrl编码文件名并处理Vite BASE_URL；图片弹层与故事/人物弹层使用portal，避免共享装饰滤镜影响fixed定位。普通滚轮缩放人物，Ctrl/Meta组合不拦截浏览器缩放。极矮窗口允许全屏人物画布缩小，保证放大文字后的收起按钮仍在窗口内。

合并时移除home分支附加的旧展览样式块，保留gallery分支完整的新响应式布局；响应式测试改用作品的语义标题，并先从故事书进入文字阅读，避免将新业务改回旧界面。

## 运行与部署

npm install安装，npm run dev打开开发服务器；runStart.cmd从自身目录启动并在缺依赖时安装。npm run build输出dist，npm run preview预览。相对base与hash路由支持静态子目录。npm run build:standalone生成standalone，整目录可通过file协议打开；根双击打开.html为其入口。

离线构建内联38张人物portrait/base以支持Canvas导出，并内联九张探源配色蒙版；其他图片使用配套assets目录。构建输出、依赖和浏览器报告均不纳入Git。CI按配置安装、执行逻辑/两种构建/浏览器/记忆检查；提交推送不等于生产托管部署。
