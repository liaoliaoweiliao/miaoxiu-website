# 系统架构

## 模块职责与边界

App管理五路hash、搜索、装饰开关与弹窗。SiteBackground保持靛蓝底色、布纹multiply及原花鸟滚动；导航小印章和页脚保持。SourcesPage仍仅使用sources.js中的两项素材。

ExperiencePage恢复原三个板块，保留左侧角色选择。移除JourneyProgress、观察手记、主题预览、装扮说明卡和单件藏品横向布局。未解锁提示恢复棋子图标、标题、说明与返回按钮。DecodeGame将唯一反馈放到图片后8px，操作按钮在其后。

## 数据流与依赖

gameModel.reducer中，只有find命中图片才增加collection.unlocked；浏览锁定主题不会解锁。每轮drawGender/drawStart要求found且theme与当轮图片相同，历史解锁不能跳过本轮。lastDraw代表本轮已抽取的一套，角色/主题/还原形象不能清除它来重抽；抽卡角色与主题在抽后禁用，装扮区仍可浏览其他角色旧藏品。只有equip本轮lastDraw才能完成穿戴并进入下一轮。

换图排除当前图片，同步theme、清空旧filter/selectedCard及提示，重置本轮寻纹、选角、抽取与穿戴完成状态，保留收藏及男女穿戴。轮次仅本次体验会话有效，已撤回完成次数计数。

选择抽卡角色后，经drawRef聚焦并即时定位抽取区域，复用html的scroll-padding-top，避免重复扣除导航高度。卡片高度用clamp/100svh适配窗口，服装object-fit:contain。等待/轮播/揭晓保留同一尺寸与提示占位；不在抽取或揭晓阶段强制滚动。

useExperience继续使用localStorage miao-wardrobe-v4兼容v3/v2，3000ms轮播、1500ms揭晓；减少动态停止动画但不隐藏寻纹图。无新增后端、依赖或图片，资源仍经assetUrl处理。

卡底prize-footer不再绝对定位，参与flex布局并保留等待/抽取时的隐藏占位；文案位于卡片下方18px，外框不压住文字。减少舞台底部冗余padding，继续保持卡片与抽取按钮完整同屏。跳转按钮复用save-btn与loop-step-btn原红色圆角样式，移除衣橱局部蓝色全宽覆盖。

## 运行与部署

npm install/dev与runStart.cmd开发，npm run build生成dist，npm run preview预览。相对base/hash路由保持。本轮独立4187预览与test-results/caption-playwright.config.mjs运行Edge，避免Windows默认webServer清理挂起。交付origin/嘉玲，不执行托管部署。
