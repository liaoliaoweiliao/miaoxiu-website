# 系统架构

## 模块职责与边界

App管理五路hash导航、受控搜索、装饰开关与全局图片弹窗。Header管理手机菜单和窄屏搜索，原标志、行楷标题和原图印章保留。本轮不修改状态逻辑或页面内容，之前首页/探源约20%字号放大保留。

main.jsx只引入index.css；顺序为base/各页面、page-background、embroidered-theme、moon-cursor、responsive。page-background.css管理共享颜色/边框/装饰强度；embroidered-theme.css管理导航、各断点和首页绣框。Header保持桌面75px、手机62px和矮窗口非sticky规则。

SiteBackground位于App首层，固定负层级，aria-hidden且不接收指针事件。深靛渐变上叠indigo-weave.svg布纹、miao-stitch-field.svg细小针脚、两侧miao-embroidery.svg蝴蝶/八角星/菱形/枝叶。大纹样重复纵向排列、向正文渐隐；miao-ribbon.svg同时用于侧边、导航下边和页脚上边。旧indigo-embroidery.svg已被替换删除，历史花鸟底图仍不恢复。bloom只改变大纹样、细底纹和展览边绣透明度，不对body/#root/内容滤镜或调色。

导航伪元素承担布纹和彩色绣边；活动导航用朱红织片底和彩色针脚，手机菜单带细底纹，键盘焦点、搜索/汉堡按钮保留。展览仍使用透明公共底、局部几何绣边、18件方图和滚动绣线；首页小鸟渐隐复用新的page-indigo。

首页AtlasPage/distributionModel维护三分区、20地点和会话探索，HeritageJourney维护三段小鸟互动。探源StoryBook/StoryReader、StitchExplorer、ColorLab维护三故事、六针法和1–3色顺序映射。体验gameModel/useExperience与DrawStage维护寻纹、36套服饰、收藏穿戴、PNG及持续正反面揭晓结构。GalleryPage根据布局和滚动生成绣线，1100px单列、760px图文纵排。

## 数据流与依赖

无后端或账号服务；React props/hooks/reducer管理状态。衣橱localStorage键miao-wardrobe-v4兼容旧v3/v2，男女穿戴分开保存；地图足迹限当前会话。图片通过assetUrl处理编码与BASE_URL，CSS public资源由Vite处理；本轮新SVG均为矢量代码，无新增依赖或外部请求。

图片、故事与人物弹层使用portal；普通人物滚轮缩放保留Ctrl/Meta页面缩放。弹层限制dvh并内部滚动，关闭按钮可达；装饰层不进入地图、作品或人物树。

## 运行与部署

npm install / npm run dev；runStart.cmd从自身目录启动并补依赖。npm run build输出dist，npm run preview预览；本轮复用已存在4173服务。默认相对base和hash支持子目录，另构建/miaoxiu-website/至工程外目录，临时HTTP服务逐页检查新SVG加载后关闭。

build:standalone生成离线HTML及素材；历史快照不随源码更新。本轮未改依赖和构建配置，未重跑离线流程。Git默认TLS远程读取被重置，临时schannel参数曾成功读取，后续复核仍间歇重置；未改持久配置。Git提交推送不等于托管发布。
