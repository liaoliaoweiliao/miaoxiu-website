# 系统架构

## 模块职责与边界

App管理五路hash导航、搜索、装饰开关和图片弹窗，Header管理手机菜单与窄屏搜索。main.jsx经index.css加载基础/页面→公共背景→导航绣框→光标→响应式样式。main的首页与探源字号、卡片高度、侧栏、换行及地图标签放大，与嘉玲主题声明同时保留。

SiteBackground为固定负层级画布，底色#165981/#1A6089/#15537B；indigo-weave.svg以0.07/multiply显示布纹，indigo-embroidery.webp以原比例裁切、渐隐、lighten显示花鸟，默认0.90、装饰开关1.00、手机乘0.90。左右随滚动反向最多65px，使用被动事件、requestAnimationFrame和ResizeObserver；减少动态时静止。滤镜仅作用装饰，不改变作品和人物。

Layout/embroidered-theme.css管理导航/页脚；保留行楷标题、0.95em右下角红印章、栏目宋体、回旋线饰和键盘focus-visible。EmbroideryOrnament与embroidered-band.svg用于导航和页脚，背景没有额外星花小纹样。各模块直接引用surface-indigo/deep/inset/hover和RGB透明渐变；探源配色挑战和页脚至少相隔48px。

首页HeroCarousel与HistoryPage的纹样按钮用居中SVG折线，保留原aria-label/事件；探源说明无局部矩形底色。DrawStage持续挂载正背面，由隐藏预览正面计算自然高度；抽取轮播绝对定位在同一舞台，卡片visibility隐藏保留占位。标题、页脚、后续装扮按钮持续占位，提示预留桌面两行/手机三行；保持3000ms抽取、1500ms揭晓，不新增强制滚动。

## 数据流与依赖

无后端/账户服务。React props/hooks/reducer管理交互，衣橱localStorage键miao-wardrobe-v4兼容v3/v2；地图探索限会话。assetUrl编码素材路径和BASE_URL，CSS路径由Vite处理。弹层使用portal、dvh与内部滚动，人物普通滚轮缩放，Ctrl/Meta保留浏览器缩放。

SourcesPage仅从sources.js读取两项素材，影像2项，空研究组不渲染；不再汇入DISTRIBUTION_SOURCES。distribution.js与地图独立数据保留，地域参考见数据口径文档；背景来源与格式参数见indigo-theme.md。本次依赖、锁文件与启动脚本不变。

## 运行与部署

npm install / npm run dev；runStart.cmd自行定位并补依赖。npm run build生成dist，npm run preview预览，默认相对base/hash路由不变。build:standalone流程及历史离线归档保持。本轮在Windows Edge用默认Playwright配置自动管理4173生产预览，完整退出；交付目标main → origin/main，不涉及托管发布。
