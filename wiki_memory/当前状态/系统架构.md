# 系统架构

## 模块职责与边界

App管理五页hash导航、搜索目标修订号、主题和全局图片弹窗。SiteSearch生成具体内容结果，HistoryPage接收appState，搜索打开新版StoryBook或定位针法/纹样。底部体验按钮及专属样式已随静涛提交删除，四主导航及页脚继续提供入口。

ParticleHeritage管理五组/三密度/手动操作和设备，WeavingIntro/weavingModel绘制等比织布与轻振飞蝶；fiberMotion统一维护有序往返、握拳暂停及原位续播，particleRenderer绘制十二层固定染色纤丝、微光三角带和20/50/100万短纤维点。手动选择可从手势暂停切回操作，WebGL失败显示原图。

ExperiencePage/useExperience/reducer管理当轮寻纹、单次抽取、收藏和穿戴；useDressupScroll保留左栏独立/藏品末尾联动滚动，换轮归零。桌面寻纹两条提示向左微移16px；完成按钮在左栏普通内容流内使用朱红金边、加粗及键盘焦点，禁用保持低亮度。展览保留18件绣线长卷。

## 数据流与依赖

无后端；localStorage miao-wardrobe-v4保存历史解锁、36套收藏与分性别穿戴。每轮先寻纹、只能抽一次，当前人物先显示原始形象，穿戴任意已有完整套装后手动完成换轮。

桌面useExperience传入createExperienceState的restoreOutfit选项，初进体验页用已校验的收藏恢复男女穿戴；网页不传该选项。新轮次仍清除outfitChosen，收藏JSON不变，恢复的套装不能绕过当轮寻纹/单抽。数据位于%APPDATA%/MiaoxiuDesktop，移动exe不改变数据目录；另存为经隔离桥和主进程校验后交Windows原生对话框。

新增锁定依赖@mediapipe/tasks-vision 1.1.1；模型/WASM/许可在public/assets/home/hand-tracking。用户开启摄像头后用模块Worker本机识别，张手稳定420ms开始、握拳首次有效识别冻结、失手1.2秒暂停，摄像头/麦克风离页或隐藏停止并释放。图片和模型URL由assetUrl处理；不录制或上传。需HTTPS/localhost、模块Worker、WASM SIMD及OffscreenCanvas，不支持时手动体验。

## 运行与部署

Node>=22.12（建议24）；npm install/dev、runStart.cmd、npm run build/preview、build:standalone保留。Electron45 + builder26.15.3 portable x64，miao://app从ASAR提供生产资源，MIME含application/wasm；CSP仅增加本地Worker/WASM能力，页面仍sandbox/contextIsolation且无Node。主进程对内置主frame的摄像头/麦克风请求逐次原生确认，默认权限检查及其他权限拒绝；远程资源阻断。desktop:pack生成1.0.1，test:desktop从package版本选择最终exe并复制到工程外独立运行。当前源码已重新打包验收，旧1.0.0仅保留历史。
