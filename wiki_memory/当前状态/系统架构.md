# 系统架构

## 模块职责与边界

2026-10-21撤销章节导航与灵感签：Header/Footer恢复 `Layout.jsx` 原实现；移除专属导航数据、CSS及加载入口，主导航继续由App管理hash路由。原搜索和手机菜单保留。

App 管理五路 hash 导航、受控搜索、装饰主题和全局图片欣赏。四个主页面各自维护交互：Home 嵌入地域 Atlas 和三段小鸟长卷；History 提供三故事九节、十种纹样、六针法与三色配色；Experience 提供随机单图寻纹、三主题永久解锁、男女角色36套服装抽取/收藏/穿戴；Gallery 保留18件去重展品和馆藏详情；Sources 展示影像与研究来源。

features/home 管理长卷动画；features/history 管理探源/图谱reducer和故事弹层；features/experience 管理随机回合、藏品、观看器与PNG；features/cursor 管理React蝴蝶光标。首页小鸟长卷使用 `home/heritage-long-panorama-wide.webp` 与 `home/bird-flap-clean.png`；按钮动画、长卷平移和三段状态仍由React组件管理。components/Frame、Layout、ImageLightbox提供公共装饰/布局/缩放拖拽预览。数据与JSX分离；styles/各页及atlas、背景、光标样式独立组织。

`src/styles/home.css` 控制长卷视觉；上下边缘伪元素复用首页共享花鸟背景并用CSS蒙版渐隐，位于标题和阶段提示之下，不介入React交互状态。

首页 Atlas 的地域导览数据由 `src/data/distribution.js` 保存（三个分区、20个县级地点、七项来源），简化省级轮廓及县级中心保存在 `src/data/atlasGeography.js`；`src/features/home/distributionModel.js` 管理筛选、选中、去重统计、固定色阶热力和会话内探索进度。`AtlasPage.jsx` 当前仅渲染地图及看板，地图的定位针、已选中标签、当前选择和右侧详情使用同一选中状态；`distribution.css` 使用首页深蓝/暖金/朱红，样式独立于其他页面。

2026-10-21按用户截图移除地图下方的服饰图、探源跳转、完整非遗档案及资料折叠区，`HomePage` 不再向Atlas传图片弹层或导航回调。`src/data/atlas.js` 的七条记录继续用于关联计数及外部官方链接；照片文件、署名与来源保留，原 `atlasModel.js` 的年份模型仍由逻辑测试验证。来源页继续从分布数据派生地域参考，运行时不调用外部地图服务。

2026-10-21，gallery.css使用共享变量--gallery-photo-size保持18张缩略图相同宽高。宽屏沿用11.5cqw的长卷画框坐标，760px及以下改为正常文档流图文列表，图片尺寸clamp(88px,26cqw,160px)，正文最低12px、作品标题最低16px；不再将手机上的整卷文字缩到几像素。缩略图居中等比裁切填满正方形；GalleryPage仍传原始src给ImageLightbox，点击后查看完整原图。

public/assets保留320个最新远程素材及52个旧版兼容素材，共372个文件；按页面/common/vendor分类，第三方许可随素材保留。docs/archive为旧离线快照，docs/references为历史素材说明；不把远程误提交的node_modules/dist/standalone作为源码纳入。

全站的responsive.css在样式入口末尾加载，负责容器边距、导航、网格、地图坐标面与弹窗的宽高适配。地图SVG及HTML地点共享820:460等比面，窄屏预留上下空间并约束选中标签横向位置；已移除横向自动滚动逻辑。Header管理临时搜索展开状态；小鸟在resize和第一段飞行中重新居中，提示框限制在长卷视口内；ImageLightbox用ResizeObserver约束放大后平移。人物观看器保留普通滚轮缩放人物，Ctrl/Meta组合事件不拦截。

2026-10-21，main.jsx在基础index.css之后加载`embroidered-theme.css`，集中覆盖共享花鸟背景的遮罩与黛青暖铜色调、桌面导航垂直位置，并限定小屏滚动背景行为。HomePage主题卡中的`feature-embroidered-frame`以断续绣线和四角菱形针脚表现边框；素材来源页复用花鸟底纹，作品展览仍使用其整幅刺绣长卷背景。该CSS只调整主题，不改变页面状态或数据流。

## 数据流与依赖

用户选定React + Vite；Agent在授权迁移范围内选择JSX、hooks/reducer、原生hash导航与public素材，以保持静态站独立运行。全部业务以远程82f079f为最新依据，初版旧三关/单次奖励逻辑已被新版回合/多次整套抽取替代。普通组件不使用HTML字符串或innerHTML。

无后端/账户/API依赖。Experience收藏使用miao-wardrobe-v4，兼容v3整套格式与v2发现；抽卡优先未拥有服饰，男女穿戴各自保存。搜索每次带请求序号，重复同主题也会触发卡池选择。动画、事件、ResizeObserver、加载取消由组件生命周期管理；弹层portal挂body，装饰滤镜限制到#root，避免fixed定位漂移。

assetUrl组合Vite BASE_URL并编码路径。离线构建只将38个人物portrait/base转为data URI以允许file协议Canvas导出，其余图片继续用配套assets目录；普通HTTP构建不嵌入这些人物图片。

## 运行与部署

npm install安装；npm run dev自动打开5173；runStart.cmd检查Node/npm并在缺Vite时安装。npm run build→dist，npm run preview→4173。base './'和hash支持静态子目录。npm run build:standalone→standalone，根双击打开.html跳到该目录；交付离线版须携带整个目录。

运行与构建依赖Node，Python3.10+只供记忆工具。CI配置npm ci、逻辑、两类构建、浏览器和记忆检查。提交推送不等同于生产托管部署。
