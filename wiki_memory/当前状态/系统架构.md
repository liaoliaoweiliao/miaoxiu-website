# 系统架构

## 模块职责与边界

2026-10-25探源绘本由StoryBook管理cover/open/closing三阶段，关闭后等待1.4秒CSS动画完成再卸载，1.6秒计时作为动画中断兜底；重复关闭被忽略，提前关闭清理开书计时。左半页以中缝为轴rotateY(180deg)向右翻合，背面复用现有封面，随后居中淡出。减少动态效果偏好下直接关闭；弹层关闭恢复滚动与原触发按钮焦点。HistoryPage仅保存故事索引，不再挂载StoryReader或提供onRead；故事原图、文字数据和其他探源功能保留。

网页沿用 React props/hooks/reducer；App 管理 hash 五页导航、搜索与全局弹窗，页面及 home/history/experience 模块保留现有交互，公共背景/样式仍采用当前 main 的靛蓝体系。桌面主进程提供窗口、菜单、自定义资源协议与系统保存；隔离 preload 只提供 saveImage。

## 数据流与依赖

无后端。衣橱 localStorage miao-wardrobe-v4 延续原校验与迁移，Electron Chromium 存于 %APPDATA%/MiaoxiuDesktop（可写，副本共享），测试可用绝对 --user-data-dir 隔离。地图探索和寻纹轮次仍为会话状态。网页原收藏与桌面不自动迁移。

miao://app/ 映射 ASAR 内 dist，路径/MIME/CSP 校验、禁止远程内容请求；assetUrl 生成兼容 BASE_URL 的编码绝对 URL，解决 CSS 自定义属性人物蒙版相对 stylesheet 多一层 assets 的问题。字体、故事、动画素材和全部资源已本地。Canvas 导出 PNG 经保存桥发送图片字节，主进程校验主 frame/格式签名/大小并弹原生位置选择后写入，结果/取消回传 reducer。网页仍原生下载。

## 运行与部署

桌面ICO原图为electron/logo-source.png，scripts/create-desktop-icon.ps1使用Windows System.Drawing生成16–256像素九尺寸electron/icon.ico；主窗口、Windows exe与portable外壳继续共用该图标。脚本是开发期格式转换工具，不是用户运行依赖。

Node >=22.12（建议24）用于开发，npm install/dev 与 runStart.cmd 保留；npm run build/preview、build:standalone 保留。桌面 npm run desktop:pack：生产构建后 electron-builder portable x64（Electron45.0.0 / builder26.15.3），同盘 node_modules/.cache/electron-builder 缓存避免本机系统目录 EXDEV；可传已按官方 SHA256 校验的 electronDist ZIP。普通用户仅双击 exe，内置 Chromium 和资源，无运行时下载。sandbox/contextIsolation/webSecurity、CSP 和 ASAR fuses 启用，关闭 Node 集成、webview 与权限请求。外部 http/https 仅交系统浏览器。
