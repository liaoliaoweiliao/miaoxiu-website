# 系统架构

## 模块职责与边界

App管理五路hash、搜索、装饰开关和弹窗。Header保留标题桌面30–38px、平板20–25px、手机18–25px；红印章0.95em、bottom:0、标题右侧留白0.65em，位于标题右下角，所有测试断点避开底线至少6px。栏目宋体/回旋线饰与键盘focus-visible保留，点击无角框。Footer沿用蝴蝶线章、几何绣带和原花鸟。

SiteBackground为固定负层级画布；page-background.css管理#165981/#1A6089/#15537B。布纹0.07且multiply避免叠白；花鸟lighten保留彩线，滤镜降为saturate(1.25) brightness(1.15) contrast(1.1)，默认0.90/开关1.00、手机乘0.90。只保留原左右花鸟随滚动反向最多65px，背景额外小纹样及针脚串联DOM/CSS已撤掉。原被动监听、requestAnimationFrame、ResizeObserver与减少动态效果保留。

板块统一用--surface-indigo #1B557C、deep #174C72、inset #18496C、hover #24658D和RGB透明渐变；直接修改base/home/distribution/history/experience/gallery现有背景声明。覆盖首页章节/地图看板、探源工具、互动卡池/藏品/人物和展览文字/针结，来源页透明。未新增覆盖样式表。

首页HeroCarousel与探源HistoryPage在原按钮内绘制20×20 SVG折线，路径对称且网格居中，沿用原aria-label、事件与按钮尺寸；探源图形桌面20px/手机16px。探源.motif-art-copy背景为none，文字、图片、整图渐变与放大镜保留。

DrawStage将正背面持续放在同一网格中，隐藏的预览正面计算自然高度，等待时仅显示卡背。抽取轮播绝对定位于同一舞台，卡片visibility隐藏保留占位；标题、页脚、后续装扮按钮持续占位，提示预留两行/手机三行。三个状态共享尺寸与间距，减少动态也不改变结构；无抽卡强制滚动。useExperience及reducer保持3000ms抽取、1500ms揭晓和原收藏流程。

## 数据流与依赖

无后端/账户；衣橱localStorage miao-wardrobe-v4及旧版兼容保持。assetUrl处理资源编码和BASE_URL，CSS图片由Vite处理。复用已有背景，无新增依赖、图片或在线字体。

SourcesPage只从src/data/sources.js的两项静态清单读取并自动统计影像2项，研究资料组为空时不渲染。sources.js已移除DISTRIBUTION_SOURCES与assetUrl导入，不再汇入背景、线饰、地图图片或地域参考条目。只替换来源页清单；地图/作品/背景本身和distribution.js内的数据参考保持。背景来源与格式参数继续记在docs/references/indigo-theme.md，地域参考在支系分布数据口径文档。

清单依据用户xlsx的Sheet1!A2:E3：苗绣龙纹/PDF/纹样科普/CC BY 4.0；GuizhouOct06canon 662/Flickr/摄影师@Tianjin24/作品展览/CC BY 2.0。署名及协议按原表列示，未声明已联网复核。原xlsx只读，未复制或修改。

照片、作品、地图数据、服饰与配色线稿保持；配色挑战和页脚48–76px间距保留；唯一样式入口仍为index.css。

## 运行与部署

npm install、npm run dev和runStart.cmd开发；npm run build生成dist；npm run preview预览。默认相对base/hash路由不变。本轮自行启动4174生产预览并使用无webServer的临时Playwright配置完成全套；仅关闭本轮拥有的服务，不停止他人服务。离线构建和托管未执行，Git交付目标嘉玲→origin/嘉玲。
