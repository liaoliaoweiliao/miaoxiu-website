# 系统架构

## 模块职责与边界

App管理五路hash导航、受控搜索、装饰开关和全局弹窗；Header管理手机菜单及窄屏搜索。main.jsx引入index.css，依次加载基础/页面、page-background、embroidered-theme、moon-cursor、responsive；全部采用远程嘉玲/022532c文件。

SiteBackground为固定负层级画布、布纹与左右花鸟，背景#165981/#1A6089/#15537B；布纹multiply、花鸟lighten，默认透明度0.90、装饰开启1.00，手机乘0.90。被动滚动监听经requestAnimationFrame合并并响应ResizeObserver，左右反向最多65px，减少动态偏好下静止。EmbroideryOrnament与几何绣带用于导航/页脚，背景无额外小纹样。板块共用surface-indigo系列变量，不改变内容图原色。

Layout保留四栏目、搜索、菜单、键盘焦点、标题与右下角0.95em印章；页脚复用花鸟和蝴蝶线章。首页/探源箭头为居中SVG折线；探源配色挑战与页脚至少48px间距。首页/探源字体与布局采用来源版本，不保留main独有的放大调整。

DrawStage正背面持续共享网格，隐藏的预览正面计算自然高度，轮播绝对定位，标题/卡片/页脚及提示保留占位；ExperiencePage不强制抽卡滚动，保持首次/重复/男女抽取位置。业务状态、收藏、换装与原3000ms抽取/1500ms揭晓流程保留。

## 数据流与依赖

无后端或账号服务，React props/hooks/reducer管理状态；衣橱localStorage miao-wardrobe-v4及旧版兼容，地图探索限会话。SourcesPage只读取sources.js两项清单：苗绣龙纹与GuizhouOct06canon 662；空研究资料组不渲染。distribution.js仍保留地图数据和地域参考，来源页不再汇入这些条目。署名与协议按已有清单展示，未重新联网核实。

assetUrl处理素材编码与BASE_URL，CSS资源由Vite处理。弹层采用portal、dvh高度和内部滚动；人物普通滚轮缩放，Ctrl/Meta保留页面缩放。本次package、lock、入口配置和启动脚本与原main一致，无新增依赖。

## 运行与部署

npm install / npm run dev；runStart.cmd从自身目录启动并补依赖。npm run build生成dist，npm run preview预览；standalone与历史归档流程保留。本轮构建后按默认Playwright配置使用Edge和4173预览，43项通过并正常退出。Git交付main → origin/main，不涉及托管发布。
