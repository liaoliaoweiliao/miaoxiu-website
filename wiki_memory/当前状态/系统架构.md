# 系统架构

## 模块职责与边界

App 管理五路 hash 导航、受控搜索、装饰主题和图片欣赏。Home 内嵌地域 Atlas 和三段小鸟长卷；History 提供三本图文故事书、十种纹样、六针法与 1–3 色配色；Experience 提供随机单图寻纹、三主题永久解锁、男女角色 36 套服装抽取/收藏/穿戴；Gallery 保留 18 件去重展品和馆藏详情；Sources 展示原有来源。

探源专属功能位于 features/history：StoryBook 展示附件封面与展开书页，StoryReader 保留文字阅读/键盘翻节，每本两节文字按书页转录；StitchExplorer 与 stitchGeometry 负责六种真实 SVG 线迹及同步银针；ColorLab 用九张 PNG 蒙版按选色顺序上色；historyModel 管理分组、针法播放和配色。history.css 限定探源样式，portal 弹层位于 body。公共背景与其他页面未由附件旧工程替换。

数据与 JSX 分离，图片经 assetUrl 编码并处理 Vite 基路径；2026-10-22 实际盘点 public/assets 共 386 个文件。第三方与旧版素材保留供兼容追溯，构建产物不入库。

## 数据流与依赖

React hooks/reducer 管理交互，无后端、账户或 API 依赖。Experience 使用 miao-wardrobe-v4，兼容 v3/v2，男女穿戴分开保存。Atlas 与来源资料沿用已接入数据。

探源模块选择在页面间保留于会话内存，播放计时器用 run 编号过滤过期完成事件，减少动画模式直接显示成品。配色选一色时三层同色，选两色时主/辅/主，选三色时主/辅/点缀；达到上限需先取消一种。分层 URL 直接放入 inline maskImage/WebkitMaskImage，避免 CSS 变量相对路径在外部样式表目录解析错误。

离线构建内联 38 张人物 portrait/base 图以支持 file 协议 Canvas 导出，另内联九张探源蒙版以支持 file 协议 CSS mask，其余普通图片仍走配套 assets 目录。普通 HTTP 构建保留拆包与独立图片。

## 运行与部署

npm install 安装，npm run dev 自动打开 5173；runStart.cmd 检查 Node/npm 并在缺 Vite 时安装。npm run build → dist，npm run preview → 4173；base './' 配合 hash 支持静态子目录。npm run build:standalone → standalone，双击打开.html 跳转该目录；离线演示须携带整个目录。

Node 用于开发构建，Python 3.10+ 只用于记忆工具。CI 配置 npm ci、状态测试、两类构建、浏览器和记忆检查。提交推送不等于托管发布。
