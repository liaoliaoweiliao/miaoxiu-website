# 系统架构

## 模块职责与边界

App管理五路hash、搜索、装饰开关和弹窗。Header保留标题桌面30–38px、平板20–25px、手机18–25px；红印章0.95em、bottom:0、标题右侧留白0.65em，位于标题右下角，所有测试断点避开底线至少6px。栏目宋体/回旋线饰与键盘focus-visible保留，点击无角框。Footer沿用蝴蝶线章、几何绣带和原花鸟。

SiteBackground为固定负层级画布；page-background.css管理#165981/#1A6089/#15537B。布纹0.07且multiply避免叠白；花鸟lighten保留彩线，滤镜降为saturate(1.25) brightness(1.15) contrast(1.1)，默认0.90/开关1.00、手机乘0.90。只保留原左右花鸟随滚动反向最多65px，背景额外小纹样及针脚串联DOM/CSS已撤掉。原被动监听、requestAnimationFrame、ResizeObserver与减少动态效果保留。

板块统一用--surface-indigo #1B557C、deep #174C72、inset #18496C、hover #24658D和RGB透明渐变；直接修改base/home/distribution/history/experience/gallery现有背景声明。覆盖首页章节/地图看板、探源工具、互动卡池/藏品/人物和展览文字/针结，来源页透明。未新增覆盖样式表。

## 数据流与依赖

无后端/账户，衣橱localStorage miao-wardrobe-v4及旧版兼容不变。assetUrl编码并处理BASE_URL，CSS图由Vite处理。复用317436字节的indigo-embroidery.webp，无新增依赖、位图或在线字体；导航与页脚当代SVG线饰继续保留。

照片、作品、地图数据、服饰、色卡、米白配色线稿画纸及语义强调色保留原内容色。仅改装饰和UI底色，无整页滤镜/透明度。配色挑战与页脚48–76px间距保留；唯一样式入口仍为index.css。

## 运行与部署

npm install、npm run dev和runStart.cmd开发；npm run build生成dist；npm run preview预览。默认相对base/hash路由不变。本轮复用4173已有生产预览（已确认返回当前dist）；未停止他人服务。离线构建和托管未执行，Git交付目标嘉玲→origin/嘉玲。
