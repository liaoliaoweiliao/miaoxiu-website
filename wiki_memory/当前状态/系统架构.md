# 系统架构

## 模块职责与边界

`src/App.jsx` 管理四页 hash 导航、搜索、主题、作品筛选和预览弹窗。`src/pages/` 提供 React 页面，`src/components/` 提供页头、页脚与装饰框；`src/features/experience/` 承载三关解密、一次抽卡与换装。`src/data/site.js` 保存六类纹样和五类服饰，`src/styles/` 保留深蓝金色样式。

全部 115 个既有素材保留于 `public/assets/`，按 home/history/experience/gallery/common 组织；根层重复素材暂留，不能仅凭名称删除。`docs/references/` 保存素材说明；`docs/archive/legacy-offline.html` 保留迁移前离线演示，不参与构建。

## 数据流与依赖

React 组件通过 props、回调、hooks 更新状态，不再以字符串重建全站。素材 URL 由 `src/utils/assets.js` 加上 Vite BASE_URL 并编码特殊字符。三关进度与人物选择使用浏览器 localStorage，无后端、账户或远程数据服务；具体读写容错以 `gameModel.js` 为准。

用户指定 React + Vite；Agent 在授权迁移范围内选择 JSX、hooks、原生 hash 导航和 public 静态素材，以降低四页静态站的额外依赖。保留视觉和内容，把原先未接入入口的 game.js 三关目标和单次抽卡移为实际 React feature；公共六类纹样文化介绍与三关衣橱主题独立。

## 运行与部署

`npm install` 安装依赖；`npm run dev` 打开根入口；`npm run build` 输出 dist；`npm run preview` 预览产物。Windows 双击 runStart.cmd 检查 Node/npm，缺依赖时安装。Vite 使用 React 插件与 `base: './'`；hash 导航避免静态托管 rewrite。生产应发布 dist，本轮 Git 推送不等同于站点部署。
