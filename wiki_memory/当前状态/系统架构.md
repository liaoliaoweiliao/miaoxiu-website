# 系统架构

## 模块职责与边界

App管理五路hash、搜索、装饰开关与弹窗。SiteBackground保持靛蓝底色、布纹multiply与原花鸟滚动，减少动态时静止；导航小印章位于标题右下角，页脚保留蝴蝶与几何绣带。板块引用同一组surface-indigo变量。SourcesPage仅使用sources.js的两项表格素材。

ExperiencePage组织三个互动板块与滚动/焦点目的地；JourneyProgress展示本轮步骤、会话轮次及完成次数。DecodeGame负责坐标命中与方向键观察，衣橱左侧选择男女、主区抽卡与主题进度，装扮区右侧串联藏品、纹样文化和RoundCompletion入口。手机纵向排布，单套藏品使用横向图文卡片。

## 数据流与依赖

gameModel.reducer管理round/completedRounds、解锁、抽取、穿戴与筛选。换图随机选其余两张中的一张，同时同步theme、清空旧filter/selectedCard/抽卡提示并重置本轮状态；completedRounds仅在完成穿戴后增加，手动换未解图片不计完成。收藏与两个人物的穿戴保持。

useExperience使用localStorage miao-wardrobe-v4持久化解锁/收藏/穿戴，兼容v3/v2；轮次与进度不持久化。仍为3000ms轮播与1500ms揭晓；抽取及揭晓期间禁止换轮。DrawStage隐藏正面保留自然尺寸，轮播绝对定位，按钮/提示持续占位，页脚改为舞台底部绝对定位以收紧卡片间距；悬停抽取按钮仅提亮、不位移。减少动态时不隐藏正在换图的寻纹按钮，保留焦点。

无后端、新依赖、新图片或在线字体；图片仍通过assetUrl处理编码与BASE_URL。公共数据、地图、探源、展览与来源清单未变。

## 运行与部署

npm install/dev与runStart.cmd开发，npm run build生成dist，npm run preview预览，相对base/hash路由保持。本轮使用独立4185生产预览和忽略目录test-results/rounds-playwright.config.mjs执行Edge测试，避免默认Windows webServer清理挂起。Git交付至origin/嘉玲；不执行托管部署。
