# 系统架构

## 模块职责与边界

2026-10-21，GalleryPage仍消费galleryDisplayWorks中的18件去重作品，按钮沿用App图片弹层并传递馆藏详情。SVG线路由针眼、展览轨道、18个作品针脚、轨道出口和末尾结点组成；DOM测量路线，滚动位置计算绘制长度，requestAnimationFrame平滑追随。线路到件时一次性显现对应作品；回滚缩短活动线头但保留已绣针脚和内容，返回顶部复位。移动端改为左侧轨道的单列；prefers-reduced-motion直接显示完整线路、针脚与作品。详情及验证见[功能日志](../日志/功能添加/2026-10-21-作品展览穿针引线长卷.md)。

features/home 管理长卷动画；features/history 管理探源/图谱reducer和故事弹层；features/experience 管理随机回合、藏品、观看器与PNG；features/cursor 管理React蝴蝶光标。components/Frame、Layout、ImageLightbox提供公共装饰/布局/缩放拖拽预览。数据与JSX分离；styles/各页及atlas、背景、光标样式独立组织。

## 数据流与依赖

用户选定React + Vite；Agent在授权迁移范围内选择JSX、hooks/reducer、原生hash导航与public素材，以保持静态站独立运行。全部业务以远程82f079f为最新依据，初版旧三关/单次奖励逻辑已被新版回合/多次整套抽取替代。普通组件不使用HTML字符串或innerHTML。

无后端/账户/API依赖。Experience收藏使用miao-wardrobe-v4，兼容v3整套格式与v2发现；抽卡优先未拥有服饰，男女穿戴各自保存。搜索每次带请求序号，重复同主题也会触发卡池选择。动画、事件、ResizeObserver、加载取消由组件生命周期管理；弹层portal挂body，装饰滤镜限制到#root，避免fixed定位漂移。

assetUrl组合Vite BASE_URL并编码路径。离线构建只将38个人物portrait/base转为data URI以允许file协议Canvas导出，其余图片继续用配套assets目录；普通HTTP构建不嵌入这些人物图片。

## 运行与部署

npm install安装；npm run dev自动打开5173；runStart.cmd检查Node/npm并在缺Vite时安装。npm run build→dist，npm run preview→4173。base './'和hash支持静态子目录。npm run build:standalone→standalone，根双击打开.html跳到该目录；交付离线版须携带整个目录。

运行与构建依赖Node，Python3.10+只供记忆工具。CI配置npm ci、逻辑、两类构建、浏览器和记忆检查。提交推送不等同于生产托管部署。
