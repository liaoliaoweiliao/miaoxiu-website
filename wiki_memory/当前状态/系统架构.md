# 系统架构

## 模块职责与边界

App管理五路hash、searchTarget请求及revision、装饰开关与弹窗。Layout委托SiteSearch维护输入框/短结果列表、键盘活动项与推荐词。SiteBackground沿用靛蓝底、布纹multiply和原花鸟滚动；公共导航、小印章与页脚保持。SourcesPage仍使用sources.js中的两项素材。

ExperiencePage组织原三个板块，桌面选角在衣橱左侧。最新要求已撤销新增标题静态角花/针脚，删除EmbroideryTrim及调用/样式，平板选角跨行恢复原三行。DecodeGame图片下仅保留8px间距的一条反馈。

## 数据流与依赖

data/search.js从现有history、gallery和experience levels生成48项索引；searchModel执行NFKC规范化、去空格标点、名称/关键词排序，默认最多6项并保留总数。SiteSearch用combobox/listbox语义，中文组字不提交，Esc/点外部收起；推荐词改查询，未匹配不弹alert或换无关页。

App选择合法索引ID后递增searchTarget.revision并导航，同页重复选择仍触发；普通导航清空目标，同页hash事件保留刚请求的目标。HistoryPage将内容状态更新与DOM提交后的定位分开，以handledSearch/positionedSearch各保证每个请求只执行一次；等待分类/针法匹配后聚焦滚动，避免StrictMode取消首帧或聚焦随后被卸载的旧分类按钮。GalleryPage显示并定位目标卡后复用ImageLightbox，关闭恢复该卡焦点。ExperiencePage复用moveTo定位区段或衣橱，但搜索不授予解锁/额外抽取次数。

只有find命中实际图片才增加解锁，star追加最左侧四个矩形，原13处星纹、牡丹及水涡区域保留。浏览锁定主题不解锁；每轮drawGender/drawStart要求found且主题匹配，lastDraw使当轮只能抽一套。换角色、主题或还原人物不能恢复抽取次数。

完成条件为本轮已寻纹、已抽取、当前角色主动穿戴任意已收藏完整套装；不比较equipped和lastDraw的编号。equip与gender计算dressed，drawComplete同时识别此前已主动穿好的旧套装。绘制中与揭晓中不能换轮。完成由用户点击触发，无自动跳转。

outfitChosen仅本轮有效，初次进入和换轮男女均false；visibleCollection将未主动选择角色的可见equipped派生为null，用于观看、高亮、保存与完成按钮，不清除持久化collection.equipped。换图排除当前、同步主题、清空筛选/选中卡/提示与临时状态，收藏和历史穿戴保留。

选角后drawRef聚焦并即时定位，复用html scroll-padding-top；100svh/clamp控制卡片，服装contain，等待/轮播/揭晓预留同一尺寸，不在抽取中强制滚动。红色“查看藏品并装扮”按钮保持；卡底文案参与正常布局并保留占位，避开外框及按钮。

useExperience用localStorage miao-wardrobe-v4兼容v3/v2，轮播1800ms、揭晓1500ms。横向轮播0.65s循环；揭晓服装1.1s浮现并加强静态金光和边框，服装与名称保持挂载。减少动态模式跳过等待并停止动画。无新依赖、后端或栅格图片。

useDressupScroll读取人物与藏品栏ref，以passive窗口scroll和requestAnimationFrame检测页面向下滚动；两列sticky布局下，藏品栏底部首次进入视口时将左侧滚至底部。到达后不持续追踪或锁定左侧，用户可以重新上下滚动；离开末尾再进入可再次触发。单列/矮窗不启用联动，卸载清理监听器与帧。

SiteSearch用SVG圆与斜柄代替字符放大镜，按钮grid居中、图标translateY(-1px)，桌面18px、手机22px；aria-hidden保持原按钮“搜索”可访问名称。

人物装扮两列布局下avatar-panel保持sticky，max-height为100dvh减导航与上下留白，overflow-y:auto使左侧超高内容独立滚动。900px以下单列或500px以下矮窗解除高度与内部滚动，使用正常页面滚动。LookViewer只在expanded时注册阻止默认滚动的缩放wheel监听器，退出时移除；页面内普通滚轮传给左栏或页面，按钮、键盘及双指缩放保持。全屏仍可滚轮缩放，Ctrl/Meta快捷键不拦截，提示与读屏标签按模式匹配。

## 运行与部署

npm install/dev与runStart.cmd开发，npm run build生成dist，npm run preview预览。相对base/hash保持。本轮独立4193预览与忽略目录无webServer配置测试Edge，避免Windows默认webServer清理挂起。交付origin/嘉玲，无托管部署。
