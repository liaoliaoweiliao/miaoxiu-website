# 系统架构

## 模块职责与边界

首页不再挂载HeritageJourney，改为ParticleHeritage；旧组件/素材保留但不加载。homeParticles数据引用已入库原图，经assetUrl加载；particleModel过滤透明/暗像素，采样位置和颜色。particleRenderer用原生WebGL点精灵、透视旋转、形态插值和球状散开，桌面12000/窄屏6500点，无新增依赖。不可用时原图降级，减少动态时静态切换，离开视口/隐藏文档暂停绘制，卸载释放GPU。

useParticleSensors只在点击后分别getUserMedia，摄像头40×30帧差检测运动量/镜像重心，麦克风AnalyserNode读取RMS；不输出扬声器、不录制或上传。强动作/声音带冷却触发随机重组。停止、导航卸载、标签页隐藏及延迟授权取消都会释放轨道和AudioContext；无语义手势/姿态模型。

ColorLab六色色卡以img经assetUrl读取原图，object-fit:contain完整等比显示；68px（窄屏54px）圆形框内留3px间距，外框不裁切子图片，选中色环保留。寓意正文15px、行高1.7；其余结构、数据和状态不变。

探源ColorLab空配色时不再渲染“未上色线稿”标题，但保留palette-empty提示；选色后的数量与主辅色仍显示。六色meaning扩充为视觉联想及配色建议。StitchExplorer按钮以两列文字网格展示名称和简介：简介visibility/opacity默认隐藏，hover或focus-visible时显示在名称右侧；名称与简介继承同一字号，窄屏仅在右侧简介列换行，预留空间防悬停抖动。aria-label保留完整语义，点击针法的状态和动画未变。

探源龙纹数据指向motif-dragon-user.png，展示和放大镜复用同一原图。ColorLab保留三栏、三纹样、六色色卡与1—3色分层、清空及寓意联动；配色示例行、寓意底部配图和配色挑战已按用户圈选删除，historyModel同步移除colorExample/challenge及对应action，colorExamples数据不再导出。保留其他素材和现有布局样式。

探源StoryBook保留cover/open/closing三阶段；左页沿中缝向右翻合0.8秒，背面使用用户2026-10-25提供并原样保存的closed-book-user.png，使用contain保留比例、透明背景与自然阴影。原右页在0.2～0.28秒淡出，封面朝向读者前已隐藏，避免透明边缘露出内页，居中短暂停留，绘本约1.15～1.62秒独立淡出，遮罩最后退场，1.8秒结束；2秒计时兜底。封面在挂载时preload。减少动态效果偏好仍直接关闭；重复关闭、计时清理、焦点/滚动恢复保留。HistoryPage不挂载文字阅读弹窗。

网页沿用 React props/hooks/reducer；App 管理 hash 五页导航、搜索与全局弹窗，页面及 home/history/experience 模块保留现有交互，公共背景/样式仍采用当前 main 的靛蓝体系。桌面主进程提供窗口、菜单、自定义资源协议与系统保存；隔离 preload 只提供 saveImage。

## 数据流与依赖

无后端。衣橱 localStorage miao-wardrobe-v4 延续原校验与迁移，Electron Chromium 存于 %APPDATA%/MiaoxiuDesktop（可写，副本共享），测试可用绝对 --user-data-dir 隔离。地图探索和寻纹轮次仍为会话状态。网页原收藏与桌面不自动迁移。

miao://app/ 映射 ASAR 内 dist，路径/MIME/CSP 校验、禁止远程内容请求；assetUrl 生成兼容 BASE_URL 的编码绝对 URL，解决 CSS 自定义属性人物蒙版相对 stylesheet 多一层 assets 的问题。字体、故事、动画素材和全部资源已本地。Canvas 导出 PNG 经保存桥发送图片字节，主进程校验主 frame/格式签名/大小并弹原生位置选择后写入，结果/取消回传 reducer。网页仍原生下载。

## 运行与部署

桌面ICO原图为electron/logo-source.png，scripts/create-desktop-icon.ps1使用Windows System.Drawing生成16–256像素九尺寸electron/icon.ico；主窗口、Windows exe与portable外壳继续共用该图标。脚本是开发期格式转换工具，不是用户运行依赖。

Node >=22.12（建议24）用于开发，npm install/dev 与 runStart.cmd 保留；npm run build/preview、build:standalone 保留。桌面 npm run desktop:pack：生产构建后 electron-builder portable x64（Electron45.0.0 / builder26.15.3），同盘 node_modules/.cache/electron-builder 缓存避免本机系统目录 EXDEV；可传已按官方 SHA256 校验的 electronDist ZIP。普通用户仅双击 exe，内置 Chromium 和资源，无运行时下载。sandbox/contextIsolation/webSecurity、CSP 和 ASAR fuses 启用，关闭 Node 集成、webview 与权限请求。外部 http/https 仅交系统浏览器。
