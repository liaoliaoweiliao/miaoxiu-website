# 系统架构

## 模块职责与边界

App管理五路hash、搜索、装饰开关和图片弹窗。Header保留品牌、原印章、搜索与窄屏菜单；标题桌面30–38px、平板20–25px、手机18–25px，原图印章1.55em。栏目为宋体、回旋双线与四种线饰，选中仅改变色彩及标记，不显示点击框；键盘focus-visible保留。Footer使用蝴蝶线章、题字、几何绣带与两侧彩色花鸟。

SiteBackground为固定负层级共享画布，body隔离层级。page-background.css管理#245B85/#2D6B95/#1C4D76、布纹0.055、花鸟0.90/1.00（手机乘0.90）和展览边绣0.40/0.55。lighten混合保留彩色绣线，装饰层滤镜不改变作品/地图/服饰。花鸟按原比例裁切、向中央渐隐、不平铺；上下各80px余量，滚动时左右反向移动最多65px；新增串联的小纹样分别移动260/280px并改变显现强度。

滚动使用被动监听和requestAnimationFrame合并，进度按当前页面长度计算；ResizeObserver感知路由与内容高度变化，窗口resize重新计算。减少动态效果时进度0/transform none；清理监听、观察器和待执行帧。无定时动画和整页rerender。

## 数据流与依赖

无后端或账户服务；衣橱localStorage miao-wardrobe-v4及旧版兼容不变。assetUrl处理JSX路径编码和BASE_URL，CSS图片由Vite处理。复用indigo-embroidery.webp（1672×941，317436字节），新增代码线饰/SVG，无新增依赖、位图或在线字体。来源页明确区分已有AI背景和本站绘制的当代线饰。

首页地图/小鸟、探源故事/针法/配色和体验reducer沿用原实现；history main底部48–76px内边距隔开配色挑战与页脚。样式继续经唯一index.css加载。

## 运行与部署

npm install、npm run dev和runStart.cmd开发；npm run build生成dist；npm run preview预览。默认相对base/hash路由不变。本轮复用4173已有生产预览（已确认返回当前dist）；未停止他人服务。离线构建和托管未执行，Git交付目标嘉玲→origin/嘉玲。
