# 系统架构

## 模块职责与边界

App管理五路hash、搜索、装饰开关和图片弹窗；Header管理菜单及窄屏搜索。Layout内通过assetUrl保留用户朱红原图印章，尺寸随标题缩放且不拦截点击。main.jsx只导入index.css，依次加载基础/各页、公共背景、导航、光标、响应式规则。

SiteBackground为固定、负层级、pointer-events:none的共享画布，body隔离层级。page-background.css唯一管理底色、表面、导航、暖金与纹样变量；indigo-weave.svg负责纤维，indigo-embroidery.webp负责两侧花鸟/蝴蝶/几何针线。两侧分别取原图左右边缘，auto 100%保持比例，mask渐隐，不平铺；长页面不增加图片高度，不监听滚动。花鸟层filter只降低装饰饱和度；开关调0.09→0.13，手机乘0.75，内容不变。远程原有indigo-embroidery.svg保留但本轮不再引用；旧page-background.webp/floral-corner.webp已由远程删除。

作品展览保持透明主背景和少量几何绣边，18件作品/滚动绣线/原作弹窗不变。Header使用98%深靛蓝底、一像素疏针脚与简化暖金菱结；默认/悬停/当前/键盘聚焦仍分明。源数据增加背景署名，SourcesPage支持人类可读的查看链接文字。

首页AtlasPage/distributionModel提供三分区、20处地点及会话足迹，HeritageJourney管理三段小鸟。探源StoryBook/StoryReader、StitchExplorer和ColorLab管理故事、六针法与1–3色蒙版。体验gameModel/useExperience管理寻纹和36套收藏/穿戴/PNG；DrawStage保留稳定正反卡面、一次金色揭晓与名字渐入。GalleryPage以ResizeObserver/滚动生成18处针结绣线路径；1100px单列、760px图文纵排。

## 数据流与依赖

无后端或账户服务，React状态组织交互；衣橱localStorage miao-wardrobe-v4兼容旧版本，男女穿戴分别保存。assetUrl编码路径并处理Vite BASE_URL，CSS图由Vite处理。背景WebP317436字节、1672×941，源PNG3271511字节，约缩小90%；两侧共用同一资源，无新增依赖。

弹窗使用portal，普通滚轮缩放人物、Ctrl/Meta保留浏览器缩放，短窗口内滚动且关闭按钮可达。背景独立，不进入作品、地图、人物图像树。

## 运行与部署

npm install、npm run dev及runStart.cmd用于开发；npm run build生成dist，npm run preview预览。默认相对base/hash，另验证/miaoxiu-website/子路径。4173为本轮启动的生产预览。build:standalone生成离线目录及内联人物/蒙版，其他图片须随assets携带，本轮未运行。Git交付目标嘉玲→origin/嘉玲，不代表托管部署。
