# 系统架构

## 模块职责与边界

App 管理五路 hash 导航、受控搜索、装饰主题和全局图片欣赏。四个主页面各自维护交互：Home 嵌入地域 Atlas 和三段小鸟长卷；History 提供三故事九节、十种纹样、六针法与三色配色；Experience 提供随机单图寻纹、三主题永久解锁、男女角色36套服装抽取/收藏/穿戴；Gallery 保留18件去重展品和馆藏详情；Sources 展示影像与研究来源。

features/home 管理长卷动画；features/history 管理探源/图谱reducer和故事弹层；features/experience 管理随机回合、藏品、观看器与PNG；features/cursor 管理React蝴蝶光标。首页小鸟长卷使用 `home/heritage-long-panorama-wide.webp` 与 `home/bird-flap-clean.png`；按钮动画、地图平移和三段状态仍由React组件管理。components/Frame、Layout、ImageLightbox提供公共装饰/布局/缩放拖拽预览。数据与JSX分离；styles/各页及atlas、背景、光标样式独立组织。

首页 Atlas 将官方非遗名录数据和按地点核对的图像引用保存在 `src/data/atlas.js`；选中雷山、剑河或台江记录时展示对应服饰参考图及作者/许可链接。其余地区保持名录数据，不借用未经对应核实的图片。许可清单由 `src/data/sources.js` 提供给素材来源页。

2026-10-21，Agent按用户统一作品图片尺寸的要求，在gallery.css采用共享变量--gallery-photo-size:11.5cqw；18张缩略图和图片列使用同一宽高，随长卷整体缩放，不再随各画框的宽高变化。缩略图居中等比裁切填满正方形；GalleryPage仍传原始src给ImageLightbox，点击后查看完整原图。

public/assets保留320个最新远程素材及52个旧版兼容素材，共372个文件；按页面/common/vendor分类，第三方许可随素材保留。docs/archive为旧离线快照，docs/references为历史素材说明；不把远程误提交的node_modules/dist/standalone作为源码纳入。

## 数据流与依赖

用户选定React + Vite；Agent在授权迁移范围内选择JSX、hooks/reducer、原生hash导航与public素材，以保持静态站独立运行。全部业务以远程82f079f为最新依据，初版旧三关/单次奖励逻辑已被新版回合/多次整套抽取替代。普通组件不使用HTML字符串或innerHTML。

无后端/账户/API依赖。Experience收藏使用miao-wardrobe-v4，兼容v3整套格式与v2发现；抽卡优先未拥有服饰，男女穿戴各自保存。搜索每次带请求序号，重复同主题也会触发卡池选择。动画、事件、ResizeObserver、加载取消由组件生命周期管理；弹层portal挂body，装饰滤镜限制到#root，避免fixed定位漂移。

assetUrl组合Vite BASE_URL并编码路径。离线构建只将38个人物portrait/base转为data URI以允许file协议Canvas导出，其余图片继续用配套assets目录；普通HTTP构建不嵌入这些人物图片。

## 运行与部署

npm install安装；npm run dev自动打开5173；runStart.cmd检查Node/npm并在缺Vite时安装。npm run build→dist，npm run preview→4173。base './'和hash支持静态子目录。npm run build:standalone→standalone，根双击打开.html跳到该目录；交付离线版须携带整个目录。

运行与构建依赖Node，Python3.10+只供记忆工具。CI配置npm ci、逻辑、两类构建、浏览器和记忆检查。提交推送不等同于生产托管部署。
