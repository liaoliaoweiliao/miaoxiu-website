# 系统架构

## 模块职责与边界

App管理五路hash导航、受控搜索、纹样装饰和全局图片欣赏。Header管理手机菜单/窄屏搜索；保留导航标志、标题和用户原图朱红印章。印章由assetUrl引用，按标题字号缩放，纵向框裁去透明留白，aria-hidden/pointer-events:none。Header的装饰按钮通过aria-pressed表达状态。

main.jsx仅引入index.css；index.css依次加载base、各页、page-background、embroidered-theme、moon-cursor及responsive。公共背景及色彩变量唯一由page-background.css维护，导航及所有断点由embroidered-theme.css维护，responsive保留全站窗口/弹窗布局和矮窗口导航规则。清理base中三份基础块的重复副本、旧导航标记和旧全局饱和滤镜，保留最后版本的移动端轮播规则。

body保留实底及轻微渐变并建立isolation；固定伪元素以负层级承载织物和现有花鸟底图，均pointer-events:none。花鸟不重复拼接，中央mask留白；滤镜仅作用装饰。bloom只将花鸟0.08调为0.10和展览边绣0.16调为0.22；不修改内容色彩。展览取消独立重复铺图，保留局部几何绣边、滚动绣线、18件作品及原作查看；小鸟全景上下渐隐改用共享靛蓝色。

首页的AtlasPage/distributionModel提供三分区、20处地点及会话探索；HeritageJourney管理长卷三段互动。探源以StoryBook/StoryReader、StitchExplorer及ColorLab管理故事、六种针法和按选择顺序映射的1–3色蒙版。体验以gameModel/useExperience管理解密、36套男女服饰、收藏/穿戴/PNG；DrawStage以持续存在的正反面网格展示一次揭晓、星芒、扫光及名字渐入，drawRevision确保重复同套可重播。GalleryPage通过ResizeObserver与滚动测量针结、生成SVG绣线路径并依次显现，减少动效完整展示；1100px单列、760px图文纵排。

## 数据流与依赖

无后端/账户服务；React props/hooks/reducer传递状态。衣橱localStorage为miao-wardrobe-v4，兼容旧v3/v2；男女穿戴分别保存，优先补全未拥有套装。搜索序号允许同词重复触发，地图足迹仅保留当前会话。

assetUrl编码图片路径并读取Vite BASE_URL，CSS素材由Vite处理。图片、故事和人物弹层使用portal；人物普通滚轮缩放，Ctrl/Meta不拦截页面缩放。弹窗受dvh高度限制，内部可滚动，关闭按钮保持可达。原图未改写，新增装饰不进入图片/地图/人物内容树。

## 运行与部署

npm install安装，npm run dev启动；runStart.cmd可从自身目录启动并补依赖。npm run build输出dist，npm run preview预览；本轮复用已有4173服务，已核对HTTP返回HTML资源哈希与当前dist相同。默认相对base与hash支持静态子目录，另验证/miaoxiu-website/绝对子路径。

npm run build:standalone生成离线目录，人物portrait/base及探源蒙版内联以支持file协议Canvas操作；其他素材需保留配套assets，历史归档不更新。本轮无依赖或配置变化，未重跑离线构建。提交推送不等于托管部署。
