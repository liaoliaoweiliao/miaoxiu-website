# 当前约束

## 用户要求与技术约束

- 用户2026-10-23要求重做全站背景与导航，以苗绣主要色彩、特色底纹形成明显风格，适配现有内容。这一新要求替代2026-10-22低饱和灰靛蓝、极淡纹样的视觉方向。Agent在授权UI范围选择深靛底、朱红/孔雀青/暖金/银白绣线与蝴蝶、八角星、菱形组合；这是实现选择，不是用户指定的精确色值或传统纹样复刻。
- 保持React + Vite、JSX、props、hooks/reducer结构，不引入HTML字符串渲染、innerHTML或dangerouslySetInnerHTML；保留四主页面和素材来源、已有字号、图片、地图、长卷与互动。
- 背景变量集中在page-background.css，导航在embroidered-theme.css；不新增!important或整页滤镜。装饰层aria-hidden、pointer-events:none，向正文方向渐隐，手机降低强度；bloom只增强装饰，不改变原作品和人物色彩。
- 保留原导航标志、“穿在身上的民族历史”、右下朱红原图印章、搜索、手机菜单、当前/悬停/键盘焦点。保留图库滚动绣线、作品弹窗和套装金色揭晓，减少动效时直接展示。
- npm管理依赖；依赖变化同步package.json和锁文件。runStart.cmd可从自身目录启动并补依赖；public素材由assetUrl或Vite CSS资源路径处理，支持子路径。

## 兼容性与操作边界

目标为现代浏览器、Unicode/空格文件名、hash路由、静态子目录、响应式窗口与浏览器缩放。根AGENTS持续授权：修改本工程后完成验证和记忆同步，必须提交并推送实际upstream；本轮核实main → origin/main。保全无关变更，不强推、不重置、不丢弃本地或远程提交；只读不创建提交。

不提交node_modules、dist、standalone、测试报告、截图、缓存或密钥。本工程提交推送授权不等于托管发布。工程记忆保持standard五页和六类日志，刷新索引并check --require-ready。地图20地点为收录样本，热力不代表人口或完整支系分布；七项非遗档案另计。
