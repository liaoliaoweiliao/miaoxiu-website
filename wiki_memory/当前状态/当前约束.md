- 衣橱点击抽取后板块位置保持稳定，尊重抽取期间的主动滚动；正常及减少动态模式都适用。探源纹样图片两侧按钮中的箭头位于圆形正中间。

- React + Vite、JSX/props/hooks/reducer与五页交互保持；禁止HTML字符串渲染、innerHTML或dangerouslySetInnerHTML。本轮修复布局与按钮图形，原抽取、收藏、穿戴和数据规则保持。
- 滤镜/混合只在装饰层，原花鸟按比例非平铺；滚动帧合并并支持减少动态效果。资源放public/assets，JSX使用assetUrl。依赖变更同步package/lock，runStart.cmd继续自行定位并补依赖。
- 用户2026-10-20持续授权：验证与记忆同步后必须提交并推送实际upstream；本轮嘉玲→origin/嘉玲。禁止强推、丢弃提交、纳入其他任务改动。原未跟踪v1 PNG和说明保全、不暂存。
