# 当前约束

## 用户要求与技术约束

- 用户最新要求背景不泛白，各页板块底色与背景匹配且不突兀；撤掉上轮后来添加的背景小纹样；红印章缩小、放在标题右下角、不与导航边线重叠。这替代前轮放大印章和增添背景小纹样的具体实现，保留已授权的原花鸟滚动效果、导航/页脚线饰和配色挑战间距。
- Agent选择#165981系列纯蓝与相近的表面色变量，multiply布纹及较低亮度装饰滤镜。具体色值与0.95em印章为本轮实现选择，并非用户指定参数。
- React + Vite/JSX/props/hooks/reducer保持，不引入HTML字符串、innerHTML或dangerouslySetInnerHTML。保留五页、原印章素材与既有交互；只改UI底色，照片/作品/服饰及配色线稿保留自身颜色。
- 滤镜和混合只在独立装饰层，不改变内容原色；原花鸟按比例裁切、非平铺、非拼接；滚动帧合并并支持减少动态效果。
- 资源放public/assets，JSX使用assetUrl。npm依赖变化同步package/lock；runStart.cmd保持自行定位和补依赖，历史归档不更新。
- 2026-10-20持续授权要求每轮修改后验证、同步记忆、提交并推送实际upstream；本轮嘉玲→origin/嘉玲。禁止强推、丢弃提交或纳入其他任务改动。原有未跟踪v1 PNG和说明保全、不暂存。

现代Edge、Unicode路径、hash导航、宽窄窗口与原生页面缩放；手机菜单、搜索、键盘焦点可用。Git交付不等于托管发布。不提交node_modules、dist、standalone、报告、缓存和截图。standard记忆保留五页与六类日志，刷新索引并执行check --require-ready，人工核对来源。
