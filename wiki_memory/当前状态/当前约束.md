# 当前约束

## 用户要求与技术约束

- 最新要求替代上次“填充三个板块”：移除顶部三步导览、观察手记、主题预览与装扮说明卡；保持多轮玩法、左侧角色选择、卡片与按钮紧凑间距。锁定区恢复参考图一。用户已明确确认图下只保留“找到任意一处对应纹样，即可解锁该主题衣橱”这一条提示。
- 发现哪种纹样，只开启该主题本轮抽取；每轮只能抽一套，穿戴本轮抽到的服装后才能随机继续。历史收藏与男女穿戴保留，历史解锁不替代本轮寻纹。角色选择后卡片与抽取按钮应完整进入当前视野。
- 正常与减少动态模式保持抽取/揭晓布局稳定，尊重抽取中的主动滚动。选角触发的定位属于明确用户操作，不持续锁定页面。
- 继续使用React + Vite、JSX/props/hooks/reducer，禁止HTML字符串渲染、innerHTML和dangerouslySetInnerHTML；资源放public/assets并用assetUrl。无依赖变更。
- 纯靛蓝、原花鸟滚动、板块色、小印章、箭头居中与五页功能保持。来源页仍仅列用户资源表两项，不自动回填背景/地图来源条目。

现代Edge、Unicode路径、hash导航、宽窄窗口及原生缩放，保留键盘焦点、手机菜单/搜索和PNG导出。卡片视口适配已覆盖1440×900、1366×768、820×600、390×844、320×700、640×500。
