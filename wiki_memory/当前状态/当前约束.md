# 当前约束

## 用户要求与技术约束

- React + Vite及现有入口不变；使用JSX、props、hooks/reducer，不引入HTML字符串、innerHTML或dangerouslySetInnerHTML；保留五页内容、布局、字号层级、图片、地图与互动。
- 2026-10-22要求全站为偏灰靛蓝、轻微织物肌理和苗绣暗纹，导航略深且文字清楚。用户随后明确要求彻底删除旧背景并重设计，优先于原复用底图要求；现删除旧花鸟底图及页脚图，采用新SVG布纹与源自首页的蝴蝶/菱形针脚。中部留白，装饰不拦截点击或影响滚动。
- 颜色/边框/纹样强度用CSS变量集中管理，避免重复覆盖和新增!important。严禁对body/#root/整页施加滤镜或透明度；纹样开关只调整装饰层。暖金标题、导航原标志、“穿在身上的民族历史”及右下方朱红原图印章保留。
- 保留搜索、手机菜单、当前/悬停/键盘焦点、滚动绣线、作品长卷和原图弹窗；套装名字稳定展示与金色揭晓继续保留，减少动态效果时直接显示。
- npm为包管理器，依赖变化同步package.json和锁文件。runStart.cmd从自身目录启动并安装首次缺失依赖。图片在public/assets，JSX通过assetUrl兼容文件名及Vite基路径。
- 用户2026-10-20持续授权：修改本工程后完成验证与记忆同步，必须提交并推送实际upstream。本轮为main → origin/main；只读任务无空提交。

## 兼容性与操作边界

目标为现代浏览器、Unicode/空格文件名、hash路由、静态子目录、响应式窗口和浏览器缩放。保全无关本地及远程改动；开始和交付前核实工作区、upstream与远程真实引用，不强推、不重置、不丢弃提交。

不提交依赖、dist、standalone、测试报告、缓存或临时截图。本工程授权不扩大为托管发布或其他仓库。离线演示由build:standalone重新生成，历史HTML快照不随源码更新。

工程记忆保持standard五页实质状态和六类日志，刷新索引、check --require-ready并人工核对来源。首页热力仅表示20处收录样本的集中程度，七项非遗记录另计，详见数据口径文档。
