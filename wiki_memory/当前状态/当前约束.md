# 当前约束

## 用户要求与技术约束

- 2026-10-26最新要求覆盖旧“只能穿本轮套装”限制：主动穿戴任意已收藏的整套服装，点击完成可进入下一轮。仍保持对应寻纹、每轮抽一套、点击完成后随机换图；历史解锁不能代替本轮寻纹。
- 未选套装显示原始人物，进入页面及新一轮都等待主动选择；抽取不自动穿戴、穿戴不自动换轮。历史收藏与男女穿戴记录保留。
- 用户最新要求撤销先前确认添加的标题静态角花与针脚线饰，当前已移除。未来新增板块内容或装饰仍先询问；原有外框和揭晓效果不属于本次撤回范围。
- 人物装扮鼠标放左侧即可滚到左栏底部，无需先滑完右侧藏品库。两列超高时独立滚动，单列/矮窗正常页面滚动；页面内普通滚轮不再缩放人物，缩放使用按钮、双指或键盘，全屏仍可滚轮缩放。
- 最左侧截图四处星纹也能解密；轮播更快，抽中套装以聚光、服装浮现及边框突出。抽取/揭晓布局保持稳定，尊重主动滚动与减少动态偏好。
- 红色圆角“查看藏品并装扮”按钮、卡底文案避框保持。桌面左侧选角，选后完整卡片与按钮进入视野；图下仅保留用户确认的“找到任意一处对应纹样，即可解锁该主题衣橱”反馈。三步导览、观察手记、主题预览及装扮说明卡不恢复。
- 使用React + Vite、JSX/props/hooks/reducer，不引入HTML字符串渲染、innerHTML或dangerouslySetInnerHTML。图片放public/assets并用assetUrl；无依赖变更。
- 保持靛蓝、原花鸟滚动、板块色、小印章、五页功能。来源清单仅资源表两项；不回填来源，不恢复已撤回的背景小纹样。
