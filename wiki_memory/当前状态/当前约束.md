# 当前约束

## 用户要求与技术约束

- 用户2026-10-23要求背景再蓝一些、整体不能暗也不能泛白，苗绣底纹明显且像绣在布面上；滚动时纹样变化、不拼接，允许增添纹样；放大导航标题与红印章，栏目点击无框；页脚搭配背景；探源配色挑战按钮不被页脚遮挡，交付嘉玲。该要求替代前轮极低透明度深底方案及本轮尚未交付的灰蓝试调。
- Agent在授权范围选用#245B85/#2D6B95及lighten彩线、代码线饰与滚动错位。具体色值/图形属实现选择，非用户指定；线饰是当代灵感，不冒称传统纹样复原。
- React + Vite/JSX/props/hooks/reducer保持，不引入HTML字符串、innerHTML或dangerouslySetInnerHTML。保留五页内容、原印章与所有既有交互。
- 滤镜和混合只作用独立装饰层，不改变作品、地图或人物原色。花鸟按原比例、非平铺；滚动监听合并为一帧更新，并支持减少动态效果。
- public/assets存图片，JSX使用assetUrl；npm管理依赖，依赖变化同步package/lock。runStart.cmd保持自行定位并补依赖。历史归档不更新，离线演示按需重建。
- 2026-10-20持续授权：每轮工程改动完成验证与记忆同步后提交并推送实际upstream。本轮已核实嘉玲→origin/嘉玲。禁止强推、丢弃提交、纳入其他任务改动；已有未跟踪v1 PNG和说明保全、不暂存。
