# 当前约束

## 用户要求与技术约束

- 用户2026-10-25要求首页第二板块通过各自的独立按钮进入对应栏目；不可把整张卡片设为点击跳转。当前已实现，依据HomePage.jsx与本轮功能日志。

- 用户2026-10-26新要求：首页第四板块聚焦技艺如何延续、传统纹样如何进入日常。保留靛蓝、绣娘、苗寨山水、横向绣布、小鸟引导及现有花蝶纹样；不得改为鸟纹文化介绍或伪造应用联系。进度为“指尖传承 / 绣纹延展 / 走进日常”，优先原图可辨的花卉边饰对照。2026-10-25撤销的并排讲解／应用卡片仍不恢复。

- 用户2026-10-23明确要求桌面程序图标使用所给网站花蝶纹logo，替代旧“绣”字图标；原图配色、比例及透明通道保留，Windows ICO生成多尺寸。

- 用户2026-10-23要求实际交付 Electron Windows10/11 x64 单文件便携 exe、离线核心功能、原生保存、用户目录持久化和最终程序实际测试；不得只交配置或依赖旁边资源目录的裸 exe。
- 保持 React+Vite、JSX/props/hooks/reducer、四栏目/来源页及全部现有交互；禁止 innerHTML/dangerouslySetInnerHTML。public 资源经 assetUrl 编码并兼容 BASE_URL；依赖变化同步 package-lock。
- 桌面通过本地生产资源，无开发服务器/在线站点/CDN/运行时下载。Electron 沙箱与隔离，只给校验后的图片保存能力；用户选位置后写入，外部资料交系统浏览器。
- 收藏和穿戴存可写用户目录，非便携解压目录；移动exe保留用户数据。网页开发、部署、runStart.cmd 和 standalone 流程保留。

## 兼容性与操作边界

目标 Windows10/11 x64；实际仅 Windows11本机，不能将 PATH 隔离测试称为干净环境实测。构建需 Node>=22.12，普通用户不需要开发工具。未签名、无自动更新，临时目录需可写且有空间；外链需要网络。

用户2026-10-20持续授权且本次再次要求：修改本工程验证和记忆同步后，提交并推送实际upstream（本轮codex/雅恬 → origin/codex/雅恬，接续仍需重查）；只提交本轮授权内容，不强推/重置/覆盖未知改动。产物release、依赖node_modules、standalone、报告desktop-test-results等不入Git。standard记忆五页和六类日志保留。
