# 当前约束

## 用户要求与技术约束

- 用户指定 React + Vite；npm install 安装、npm run dev 启动；runStart.cmd 同步 Git，工程记忆使用 standard。
- 每次完整对话修改本工程后，完成适当验证与记忆同步，必须提交并推送实际 upstream；只读任务不创建提交。
- 2026-10-22 用户要求用 22.43.zip 替换苗绣探源，并明确选择新建/推送 origin/history，供当前 codex/history 跟踪。其他分支不可直接推定为当前分支目标。
- 保持四个主页面、素材来源页和已接入交互。以源码与用户要求为依据，不能用旧业务或附件中的旧工程说明覆盖 React 架构。用 JSX/hooks/reducer，不恢复 innerHTML 或 HTML 字符串渲染。
- npm 为包管理器，依赖变化同步锁文件；Node 版本以 package.json engines 为准。生产与离线演示从当前源码构建，输出目录不入库。

## 兼容性与操作边界

目标为现代浏览器，实际测试范围单独记录。支持空格/Unicode 素材名、hash 导航、静态子路径。离线演示携带整个 standalone，人物 Canvas 与新探源 CSS 蒙版由离线配置内联。

开始与交付前核对 remote/upstream、实际远程引用和工作区；保全用户及其他任务变更。禁止强推、丢弃提交或纳入 node_modules/dist/standalone、密钥、测试报告及临时截图。远程拒绝/认证失败等须如实报告。授权只适用于本工程 Git 交付，不扩大为部署发布或向他人发送消息。
