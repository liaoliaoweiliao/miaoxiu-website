# 项目概览

## 项目目标与阶段

苗绣文化展示与互动站，含首页、苗绣探源、互动体验、作品展览四个主页面与素材来源页。React + Vite 迁移、目录整理、启动脚本和 standard 记忆已完成。2026-10-21按用户附件适配首页：轮播、主题卡片和地域看板与附件内容对应；小鸟长卷更新为附件的全景图及透明小鸟素材，导航栏、全局背景、页脚与三段交互保留。新改动的验证和 Git 接续见[当前待办](当前待办.md)及[首页 UI 日志](../日志/UI修改/2026-10-21-首页板块素材适配.md)。

2026-10-21，用户确认将第三板块做成支系热力图及核心看板，并指定home分支。当前实现为三个地域导览分区、20处县级代表地点、6个省级地区；地图筛选、四项数据、地点介绍、随机探访和落针足迹联动。七条国家级档案及原有三张服饰图保留，配图可放大；热度表示本页样本集中程度，非人口密度。实现、口径、实际验证和Git接续见[支系热力图日志](../日志/功能添加/2026-10-21-首页支系热力图与核心看板.md)及[数据口径](../../docs/references/首页支系分布数据口径.md)。

## 核心入口

- index.html → src/main.jsx → src/App.jsx：React 挂载、五路 hash 导航、搜索、主题和图片弹窗。
- src/pages/：五页面与嵌入首页的 AtlasPage；src/features/：home/history/experience/cursor 的状态和交互。
- src/data/：图谱、故事、纹样、服饰目录、作品与来源数据；public/assets/：源码素材。
- package.json / vite.config.js / vite.standalone.config.js 定义运行与两种构建；runStart.cmd 为 Windows 启动入口。
- 根 README 为使用说明，根 AGENTS 为工程与提交推送约束；记忆导航为 wiki_memory/README.md。
