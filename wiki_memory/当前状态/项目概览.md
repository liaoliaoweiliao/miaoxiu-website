# 项目概览

## 项目目标与阶段

React + Vite苗绣文化网站保留首页、探源、体验、展览、来源五页。首页三分区20地点与三段小鸟、探源故事/六针法/1–3色配色、体验36套服饰/收藏/整套穿戴/PNG导出、展览18作品保持。

互动体验每轮先寻纹，只开启对应主题的一次抽取；穿戴任意已收藏的完整套装后，点击完成随机换图继续，不再限制为本轮抽中套装。换图排除当前照片，保留解锁、收藏及男女历史穿戴；初进页与新一轮未主动选装时仍显示原始人物。

2026-10-26按最新截图补上最左侧四处八角星纹命中区，轮播3秒缩短至1.8秒、横向流转1.1秒一周缩短至0.65秒，揭晓加强服装浮现、金色聚光与边框。用户最新要求撤销三个标题附近新增静态角花和针脚线饰，相关组件、调用与样式已移除。人物装扮左栏超高时独立滚动，不必滑完右侧藏品库；页面内人物图普通滚轮用于滚动，全屏保留滚轮缩放。原三步导览、观察手记、主题预览及装扮说明卡继续撤回。

## 核心入口

index.html → src/main.jsx → src/App.jsx。ExperiencePage组织互动，gameModel管理规则与命中区，DecodeGame负责寻纹，useExperience负责持久化及定时，DrawStage负责抽取，LookViewer管理人物观看与全屏，experience.css及responsive.css负责局部与适配样式。公共背景、导航、来源清单保持。
