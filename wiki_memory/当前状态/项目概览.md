# 项目概览

## 项目目标与阶段

2026-10-26按用户新要求完成首页“传承与新生”三段互动：指尖局部亮起、沿原绣布逐处高亮、原绣布与本子花卉边饰局部对照。保留靛蓝、绣娘、苗寨及原有花蝶纹样，小鸟仅引导；末段停留，可重看。该实现采用原长卷，没有恢复已撤销的并排讲解／应用卡片。

2026-10-25首页第二板块新增三个独立“进入栏目”按钮，分别到达苗绣探源、互动体验、作品展览；卡片本身保持展示，图片与标题点击不跳转。

2026-10-25用户要求撤销刚才的第四板块重设计，现已恢复原“传承与新生”满宽小鸟长卷；新增的三步讲解、继续按钮、应用卡片及相应数据／设计说明已撤回。原设计任务日志保留供追溯，不代表现行实现。

桌面图标已按用户2026-10-23提供的网站花蝶纹logo替换，更新交付目录和桌面同名便携exe。当前图标原图与转换脚本已入版本管理，实际重打包与启动图标/五页离线检查通过。

React + Vite 苗绣文化网站与 Electron Windows x64 离线便携应用。保留四主栏目、来源页、靛蓝花鸟背景、首页地图/长卷、三故事/六针法/配色、36套服饰抽取收藏换装导出与18件展览。当前基于嘉玲内容已集成的 main/f664f84 新增桌面封装，没有重新替换旧版本业务。

最终交付 F:/竞赛/苗绣桌面版交付/苗绣-1.0.0-便携版.exe，446892513 字节（426.19 MiB），单文件可独立运行；源产物 release/Miaoxiu-1.0.0-win-x64-portable.exe，二者 SHA256 相同。辅助使用说明与校验文件不属于运行依赖。
