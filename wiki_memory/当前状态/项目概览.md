# 项目概览

## 项目目标与阶段

React + Vite苗绣文化展示与互动网站，保留首页、苗绣探源、互动体验、作品展览、素材来源五页。本轮在远程最新背景/导航整理上统一深靛蓝织物底色，复用已有AI花鸟蝴蝶素材作为两侧暗纹；导航更深、针脚疏朗，原标志、标题、朱红印章和全部交互保留。

首页保留三分区、20处地点和三段小鸟长卷；探源保留故事书、文字、六种针法及1–3色配色；体验保留36套服饰、收藏、穿戴和PNG；展览保留18件方图作品、滚动绣线和原作弹窗。

## 核心入口

index.html → src/main.jsx → src/App.jsx管理挂载、hash导航、搜索及弹窗。SiteBackground.jsx承载独立装饰，page-background.css管理主题变量，Layout.jsx/embroidered-theme.css管理Header；各页与交互分目录维护，图片通过assetUrl处理。

素材与实现取舍见docs/references/indigo-theme.md，实际验证见本轮日志。
