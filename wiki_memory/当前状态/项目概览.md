# 项目概览

## 项目目标与阶段

React + Vite苗绣文化展示与互动网站，保留首页、苗绣探源、互动体验、作品展览和素材来源五页。当前为无亮白叠层的纯靛蓝织物、清楚的原花鸟绣纹与协调的板块蓝色；已撤销后加的背景小纹样，原花鸟滚动错位保留。导航大标题保留，红印章缩小并落在标题右下角。

首页三分区、20处地点和三段小鸟；探源故事、六针法与1–3色配色；体验36套服饰、收藏、穿戴和PNG；展览18件作品、绣线与原作弹窗保持。

本次局部修正：首页轮播用对称SVG箭头替代字体括号，探源纹样说明文字取消局部矩形底色。

## 核心入口

index.html → src/main.jsx → src/App.jsx。SiteBackground.jsx管理原花鸟背景与滚动；page-background.css管理底色、表面色与运动变量，各模块CSS直接引用同一组变量。Layout.jsx/embroidered-theme.css管理导航、页脚和印章；EmbroideryOrnament.jsx保留用于导航/页脚，不再放入背景。主题说明见docs/references/indigo-theme.md。
