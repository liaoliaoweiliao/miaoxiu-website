# 项目概览

## 项目目标与阶段

苗绣文化展示与互动网站，沿用React + Vite，包含首页、苗绣探源、互动体验、作品展览与素材来源五页。本轮按追加要求彻底移除旧背景及页脚花纹，重新设计靛蓝渐变、细微布纹、稀疏蝴蝶/菱形针脚；公共深靛蓝导航和必要面板颜色协调保留；保留原图、暖金标题、朱红印章、布局、字号层级及既有互动。

首页保留三个导览分区、20处地点、地域热力看板及三段小鸟长卷；探源保留三本故事书、十种纹样、六种逐针演示和1–3色配色；体验保留寻纹、36套男女服饰、收藏/穿戴/PNG与金色揭晓；展览保留18件方图作品、滚动绣线和原作弹窗。

## 核心入口

index.html → src/main.jsx → src/App.jsx管理挂载、hash导航、搜索、装饰开关与图片弹窗。页面、组件、交互、数据和样式分目录维护；assetUrl处理图片文件名与基路径。

背景由src/components/SiteBackground.jsx绘制，变量在src/styles/page-background.css；导航及印章在src/components/Layout.jsx和src/styles/embroidered-theme.css；样式统一从src/styles/index.css加载。运行、验证和交付说明见根README/AGENTS。
