# 项目概览

## 项目目标与阶段

React + Vite 苗绣文化展示与互动网站，保留首页、探源、体验、展览、来源五页。首页三分区20地点与三段小鸟，探源故事/六针法/1–3色配色，体验36套服饰/收藏/穿戴/PNG，展览18作品保持。

用户2026-10-25后续明确撤回三个板块填充设计：顶部导览、观察手记、主题预览和装扮说明卡已删除，恢复原三个板块与参考锁定面板。保留多轮、左侧角色选择和紧凑间距；每轮必须找到对应纹样才能抽取一套，穿戴该套后随机换图继续。选角后完整卡片与按钮同时进入视野，图下仅保留一条紧贴图片的反馈提示。

最新微调：恢复“查看藏品并装扮”的原红色圆角按钮；“一袭苗绣，与你相遇”改为在卡片下方正常占位，避开外框。

2026-10-26人物装扮默认规则：新进入体验页或开始新一轮时，未主动选择套装的角色显示原始形象，抽到服装也不会自动穿戴。只有主动整套穿戴本轮抽取服装后完成按钮才可用，由用户点击继续随机寻纹；收藏与历史穿戴记录保留。

## 核心入口

index.html → src/main.jsx → src/App.jsx。ExperiencePage.jsx组织互动页面，gameModel.js管理规则，DecodeGame.jsx负责寻纹，DrawStage.jsx负责抽取，experience.css负责布局。公共背景/导航和来源清单保持；JourneyProgress.jsx随撤回删除。
