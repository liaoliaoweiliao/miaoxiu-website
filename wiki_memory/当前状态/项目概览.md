# 项目概览

## 项目目标与阶段

React + Vite苗绣文化网站及Electron离线便携应用，保留四个主栏目、素材来源页、地图、故事／针法／配色、抽取收藏换装导出与作品展览。

2026-10-27按最新用户要求重做第四板块：以苗绣蝴蝶为唯一视觉主体，原创四翼／蝶身／触须的立体丝线结构，20万／40万／100万真实粒子，红靛金银紫配色及解构重组；以全宽舞台替代原披肩绣衣。摄像头与麦克风独立启用、合成影响纹样，分析全在浏览器本地。第四板块仍只挂载数字绣境，不恢复绣线长卷。此前撤销的花卉高亮／封面对照未恢复。首页第二板块独立栏目按钮保留。

既有桌面交付仍为F:/竞赛/苗绣桌面版交付/苗绣-1.0.0-便携版.exe；本轮只交付网页源码，没有重新打包该exe。
