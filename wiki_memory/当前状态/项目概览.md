# 项目概览
## 项目目标与阶段

React + Vite苗绣文化网站，保留首页、苗绣探源、互动体验、作品展览及来源页，另有Electron离线便携版封装。2026-11-07已集成嘉玲体验/展览及静涛探源；当前按用户新要求放宽展览图文与行距，强化绣线触发的图片淡入和文字延迟入场。

互动体验采用左侧标题、中间原比例寻纹图片、右侧常显文字档案；衣橱使用三主题标签、独立纹样原图和解锁说明，解锁后先居中选择角色，再在左栏切换角色。保持每轮寻纹、单次整套抽取、收藏、主动穿戴及手动换轮。展览18件作品逐行左右交替，内容区上限1240px，桌面图文间距112–184px、行间留白96–128px；图片最大380px。绣线到达作品针结后，图片从所在侧64–104px轻移并由透明淡入，文字延迟0.24秒跟上；手机上图下文、行间留白88px，采用小幅上移淡入。键盘聚焦立即就位，减少动态时静态显示。

探源保留三绘本、六针法、三色配色及搜索定位；故事区与纹样区统一1320px上限，三卡等宽等高，针法画布提示桌面14px/窄屏12px。首页仍采用main原有20地点居中、探访后常亮、蝴蝶入口、张手到应用/握拳回纹样、音量连续控制，不随本轮分支集成改动。
