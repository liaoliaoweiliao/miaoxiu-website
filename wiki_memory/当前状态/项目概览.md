# 项目概览

## 项目目标与阶段

本工程展示苗绣文化，包含首页、苗绣探源、互动体验、作品展览四页。用户要求迁为 React + Vite、整理目录文档、纳入 Windows 启动脚本，并建立 standard 记忆。React 迁移、目录整理、文档及 standard 记忆已实现，逻辑与浏览器验收通过；当前等待 Git 交付，见[当前待办](当前待办.md)。

## 核心入口

- `index.html` → `src/main.jsx` → `src/App.jsx`：入口、React 挂载、hash 导航与公共状态。
- `src/pages/`、`src/components/`、`src/features/experience/`：四页、公共布局、解密与换装。
- `package.json`、`vite.config.js` 定义依赖和运行方式；`runStart.cmd` 为 Windows 启动入口。
- 根 `README.md` 是工程说明，根 `AGENTS.md` 是开发约束；记忆导航为 `wiki_memory/README.md`。
