# 项目概览

## 项目目标与阶段

React + Vite苗绣文化展示与互动网站，保持五页及现有功能。公共视觉维持纯靛蓝、原花鸟滚动、协调的板块底色及标题右下角小红印章；首页轮播与探源纹样箭头居中，纹样说明文字无局部色块。衣橱等待、抽取、揭晓共享稳定占位，保留动画和用户主动滚动位置。

素材来源页依用户提供的《第三方资源说明.xlsx》Sheet1!A2:E3，仅列“苗绣龙纹”和“GuizhouOct06canon 662”，保留所列用途、链接、Tianjin24署名及CC BY 4.0/2.0。

首页三分区20地点与三段小鸟，探源故事/六针法/1–3色配色，体验36套服饰/收藏/穿戴/PNG，展览18作品/绣线/原作弹窗保持。

## 核心入口

index.html → src/main.jsx → src/App.jsx。SiteBackground.jsx管理原花鸟背景与滚动；page-background.css管理底色、表面色与运动变量，各模块CSS直接引用同一组变量。Layout.jsx/embroidered-theme.css管理导航、页脚和印章；EmbroideryOrnament.jsx保留用于导航/页脚，不再放入背景。主题说明见docs/references/indigo-theme.md。
