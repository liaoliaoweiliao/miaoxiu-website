# 项目概览

## 项目目标与阶段

React + Vite苗绣文化展示与互动网站，保留首页、苗绣探源、互动体验、作品展览和素材来源五页。当前公共视觉为鲜明靛蓝织物、清楚的彩色花鸟绣纹与随滚动变化的小纹样，导航和页脚采用同一套古典线饰。

首页三分区、20处地点和三段小鸟；探源故事、六针法与1–3色配色；体验36套服饰、收藏、穿戴和PNG；展览18件作品、滚动绣线和原作弹窗均保持。

## 核心入口

index.html → src/main.jsx → src/App.jsx。SiteBackground.jsx管理背景及滚动进度，page-background.css管理颜色/运动变量；Layout.jsx和embroidered-theme.css管理导航、页脚。EmbroideryOrnament.jsx提供四种JSX SVG线饰，embroidered-band.svg为几何绣带。探源按钮底部间距在history.css。素材说明见docs/references/indigo-theme.md。
