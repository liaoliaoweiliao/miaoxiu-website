# 项目概览

## 项目目标与阶段

探源色卡已用完整绣线填满圆盘，选择交互保留；此前验证见[修复日志](../日志/Bug处理/2026-10-27-色卡绣线填满圆形.md)。

首页维持极细半透明微光纤维网络、十二层深度和固定染色。张手稳定后有序散开并保持网络，握拳平滑聚拢为对应形态，途中反向从当前位置衔接；下一次展开/收束返回另一形态。失手/关闭摄像头暂停，既有五组/三密度、绣娘长布与飞蝶保留。

2026-10-27按用户最新红圈要求，已删除色彩解析下方“探源之后，开启互动体验”按钮、对应点击导航及专属样式；HistoryPage不再接收该按钮所用的onNavigate。色卡补全和配色等既有交互保留。原按钮演变仅见[历史日志](../日志/UI修改/2026-10-26-探源靛蓝续玩按钮.md)，当前页面不展示该入口。

早期生成的粒子蝴蝶/单包素材保存在public/assets/particles作归档；当前首页使用home/silk用户六张图，来源见首页专题。

探源六色详细寓意、15px正文、精确删字和针法悬停说明保留。

桌面图标已按用户2026-10-23提供的网站花蝶纹logo替换，更新交付目录和桌面同名便携exe。当前图标原图与转换脚本已入版本管理，实际重打包与启动图标/五页离线检查通过。

React + Vite 苗绣文化网站与 Electron Windows x64 离线便携应用。保留四主栏目、来源页、靛蓝花鸟背景、首页地图/粒子、三故事/六针法/配色、36套服饰抽取收藏换装导出与18件展览。当前基于嘉玲内容已集成的 main/f664f84 新增桌面封装，没有重新替换旧版本业务。

历史桌面交付和校验见docs/desktop-validation.md；本轮只更新网页源码。
