# 项目概览

## 项目目标与阶段

React + Vite苗绣文化网站保留首页、探源、体验、展览、来源五页。首页三分区20地点与三段小鸟、探源故事/六针法/1–3色配色、体验36套服饰/收藏/整套穿戴/PNG导出、展览18作品保持。

互动体验每轮先寻纹，只开启对应主题的一次抽取；穿戴任意已收藏的完整套装后，点击完成随机换图继续，不再限制为本轮抽中套装。换图排除当前照片，保留解锁、收藏及男女历史穿戴；初进页与新一轮未主动选装时仍显示原始人物。

2026-10-26按最新截图补上最左侧四处八角星纹命中区，轮播3秒缩短至1.8秒、横向流转1.1秒一周缩短至0.65秒，揭晓加强服装浮现、金色聚光与边框。用户最新要求撤销三个标题附近新增静态角花和针脚线饰，相关组件、调用与样式已移除。人物装扮左栏超高时可独立滚动，也可将右侧藏品库滚到末尾，左侧自动露出底部操作；页面内人物图普通滚轮用于滚动，全屏保留滚轮缩放。原三步导览、观察手记、主题预览及装扮说明卡继续撤回。

搜索已由关键词跳整页改为48项内容索引：6针法、18作品、3故事、10纹样、3互动主题及页面/区段。最多展示6项，明确名称或单项可回车直达，多项先选择；针法定位并播放、作品打开对应图片、故事打开故事书，未命中提供框旁推荐词。支持键盘、中文输入法和手机，保留原有互动规则。搜索按钮已由字符改为原生SVG放大镜，居中并上移1px。

此前撤销的展览对侧淡纹样、四处细节窗与悬停描边继续保持撤销。用户本轮明确授权“银铃引绣 · 风过花醒”：标题两侧原创SVG银饰，一主一辅，手机一件；分层微风、少量绣片与默认关闭的轻铃音已接入，保留原18作品、滚动绣线、图片观赏、搜索与装扮。
