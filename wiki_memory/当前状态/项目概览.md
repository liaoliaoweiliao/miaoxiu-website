# 项目概览

## 项目目标与阶段

苗绣文化展示与互动网站，使用React + Vite，保留首页、苗绣探源、互动体验、作品展览及素材来源五页。2026-10-22按用户“把所有分支合并”将home、history、gallery、experience的最新业务整合到main；原有本地codex分支提交均被这些历史覆盖，没有删除分支或重写历史。

首页为三个导览分区、20处地点的地域热力图与看板，并保留三段小鸟长卷；探源为三本故事书、文字阅读、十种纹样、六种逐针演示及1–3色分层配色；体验保留寻纹、36套男女服饰抽取/收藏/穿戴/PNG，并使用放大字号和“原始形象”文案；展览为18件作品的滚动绣线长卷，保留最新字号、统一方图及去章设计。

## 核心入口

- index.html → src/main.jsx → src/App.jsx：React挂载、hash路由、搜索、主题与图片弹窗。
- src/pages/、src/features/、src/data/、src/styles/分别保存页面、交互、数据和样式；public/assets/保存素材。
- package.json、两种vite配置、runStart.cmd及README定义启动与构建；AGENTS定义提交推送约束。
- [系统架构](系统架构.md)说明模块关系；完整历史在[工作日志](../日志/MOC_工作日志.md)。
