# 项目概览

## 项目目标与阶段

React + Vite 苗绣文化展示与互动网站，包含首页、苗绣探源、互动体验、作品展览及素材来源五页。首页三分区20地点与三段小鸟，探源故事/六针法/1–3色配色，体验36套服饰/收藏/整套穿戴/PNG，展览18作品与图片欣赏保持。

2026-10-25互动体验完成多轮衔接及三板块布局：顶部三步导览与完成计数、寻纹观察手记、衣橱左侧角色选择、主题套装预览和收藏进度、装扮后随机换图入口。每次换图避开当前图片，清除旧筛选并同步主题；已有解锁、收藏和男女穿戴保留。

## 核心入口

index.html → src/main.jsx → src/App.jsx。互动页面在src/pages/ExperiencePage.jsx，状态与组件在src/features/experience/，专属样式在experience.css。公共背景和导航分别由SiteBackground.jsx/page-background.css与Layout.jsx/embroidered-theme.css管理；素材来源清单仍仅为sources.js中的两项。说明见README与靛蓝主题文档。
