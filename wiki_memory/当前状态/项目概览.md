# 项目概览

## 项目目标与阶段

React + Vite 苗绣文化展示与互动网站，包含首页、苗绣探源、互动体验、作品展览及素材来源五页。2026-10-23完成全站背景与导航视觉强化：深靛布底，朱红、孔雀青、暖金和银白绣线，蝴蝶/八角星/菱形两侧纹样，彩色绣边及朱红导航选中底。本轮新要求替代此前低对比灰靛蓝的视觉方向；此前首页/探源约20%字号放大继续保留。

首页保留三分区20地点地图、地域看板与三段小鸟长卷；探源保留三本故事书、十种纹样、六种针法和1–3色配色；体验保留寻纹、36套男女服饰、收藏/穿戴/PNG及金色揭晓；展览保留18件方图、滚动绣线与原作弹窗。

## 核心入口

index.html → src/main.jsx → src/App.jsx管理挂载、hash导航、搜索、纹样装饰和图片弹窗。背景入口为SiteBackground.jsx/page-background.css；导航及印章为Layout.jsx/embroidered-theme.css；index.css统一样式顺序。素材在public/assets，JSX使用assetUrl。
