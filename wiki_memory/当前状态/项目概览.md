# 项目概览

## 项目目标与阶段

React + Vite苗绣文化网站与Electron Windows x64离线便携应用。当前main整合静涛的探源/首页粒子体验与嘉玲的搜索/多轮换装/响应布局；用户2026-10-27明确要求排除雅恬分支。四主页面、来源页、靛蓝主题、20地点地图、36套服饰和18件展览保留。

首页传承区为粒子绣娘织布→点击蝴蝶→五组传统纹样/现代应用，可选20万/50万/100万丝线。探源保留三绘本、六针法、三色配色与互动入口；已删除文字阅读入口和配色挑战。搜索可定位具体针法、纹样、故事、作品与互动主题。
