# 项目概览

## 项目目标与阶段

苗绣文化展示与互动网站，使用React + Vite，保留首页、苗绣探源、互动体验、作品展览及素材来源五页。2026-10-22首次整合四个业务分支后，用户要求撤销随后“再次合并”产生的3efd7dc；本轮按第一父提交a607580撤销该次合并的内容，并同步撤销状态。首次整合仍保留，提交历史不重写。

首页为三个导览分区、20处地点的地域热力图与看板，并保留三段小鸟长卷；探源为三本故事书、文字阅读、十种纹样、六种逐针演示及1–3色分层配色；体验保留寻纹、36套男女服饰抽取/收藏/穿戴/PNG，并使用放大字号和“原始形象”文案；展览为18件作品的滚动绣线长卷，保留最新字号、统一方图及去章设计。
