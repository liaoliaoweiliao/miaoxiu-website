# 项目概览
## 项目目标与阶段

React + Vite苗绣文化网站，保留首页、苗绣探源、互动体验、作品展览及来源页，另有Electron离线便携版封装。当前为2026-11-07按用户要求集成嘉玲的互动体验/展览和静涛的探源栏目；不纳入静涛分支独有的首页手势修改。

互动体验采用左侧标题、中间原比例寻纹图片、右侧常显文字档案；衣橱使用三主题标签、独立纹样原图和解锁说明，解锁后先居中选择角色，再在左栏切换角色。保持每轮寻纹、单次整套抽取、收藏、主动穿戴及手动换轮。展览18件作品逐行左右交替，绣线触发图文入场，手机上图下文，键盘聚焦立即就位，减少动态时静态显示。

探源保留三绘本、六针法、三色配色及搜索定位；故事区与纹样区统一1320px上限，三卡等宽等高，针法画布提示桌面14px/窄屏12px。首页仍采用main原有20地点居中、探访后常亮、蝴蝶入口、张手到应用/握拳回纹样、音量连续控制，不随本轮分支集成改动。
