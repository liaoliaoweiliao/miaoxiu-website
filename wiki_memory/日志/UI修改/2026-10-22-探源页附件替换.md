# 探源页附件替换

## 目标与结果

用户要求用 F:/22.43.zip 的内容替换“苗绣探源”。已将附件探源的四区内容与样式迁入现有 React，保留全站导航、背景、页脚及其他页面。附件旧 README/源码操作说明作为资料，不替代当前工程指令。

## 关键变更与选择

- 三张等宽故事卡，点击后封面浮动、展开附件原书页。附件源码缺少三张内页，Agent 从 index.html 的 IMAGE_DATA 提取原字节；文字阅读保留，每本按书页转录成两节，含焦点恢复和键盘关闭/翻节。
- 替换十张纹样、六张成品、三张绣线特写；新增三张色卡、九张蒙版和三张内页。保留历史素材，未复制压缩包、依赖或大离线快照入库。
- 六种针法按附件路径生成逐针 SVG，银针连续轨迹与画线进度同步，约 5.15 秒显示成品，重播与过期计时由 reducer/run 处理。放大镜使用真实 contain 尺寸与三倍细节。
- 配色一色覆盖三层，两色按主/辅/主分布，三色按主/辅/点缀；第四色需先取消一种。取消旧自动补色和组合图选择。Agent 依附件行为采用这些实现，不是额外用户需求。
- 边饰与布局使用附件专属 CSS；修正缩略图与文字相邻重叠、色卡标签间距。蒙版 URL 直接写 JSX inline 属性，避免 CSS 变量相对外部样式表解析；离线额外内联九张蒙版。
