# 展览前两张图片取景调整

## 目标与实现

用户要求作品展览第一张保留更多上方内容，第二张保留更多下方内容，并指定推送gallery分支。Agent沿用GalleryPage已支持的detailPosition字段，在gallery.js设置银冠盛装为center 20%，绣衣风华为center 70%。这两个百分比是Agent在授权范围内按原图和截图采用的常规取景值。

第一张展示更多银冠顶部，第二张展示更多下方服饰与绣裙。共享方形尺寸、其他16张默认居中、原始图片文件和点击查看全图功能保持现有实现。
