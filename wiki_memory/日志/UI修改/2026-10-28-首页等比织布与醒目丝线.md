# 首页等比织布与醒目丝线

## 目标与结果

用户要求只修首页粒子板块的比例、动作、边缘与牵引丝线，其余保留。起点静涛/c8d0d35，工作区干净；实际origin/静涛同一提交并fetch。无依赖或素材更换。

人物原裁区300×420，旧粒子映射1.67×2.04使人物偏宽；现按裁区宽高比统一映射。肩臂/倾斜/呼吸幅度约缩为三分之一，仍全身连贯运动。布面长度与厚度使用同一比例尺固定6:1，仍伸到画面右侧；6:1是Agent为长布采用的实现选择。蝴蝶原0.48纵向压缩和单轴扑翼取消，驻足与飞行均等比，大小按布面厚度容纳，驻足位置、直线飞行和阶段交接保留。

移除板块外框及硬阴影，独立底色层以横纵渐变蒙版在四边32–100px渐隐，中央保留底色；蒙版只作用底色，粒子、设备预览和控件可正常显示/点击。

细线层仍6,000条×20段；增加240束64段三角带，以3.2px手机/4.2px桌面亮芯及3.5倍宽柔光绘制。按投影曲线切线计算屏幕法向，绕过原生WebGL常见1px线宽限制。两层三角带各92,160顶点；颜色/不透明度更醒目，保留两端附着和散开重织。最初20段加粗后显露折角，最终64段细分后目视核对顺滑。跨纹样缓冲恢复同步更新粗线，所有GPU缓冲仍统一销毁。
