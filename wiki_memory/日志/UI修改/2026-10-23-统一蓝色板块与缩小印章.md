# 统一蓝色板块与缩小印章

## 目标与结果

按最新四点反馈：背景去泛白、各板块底色匹配背景，撤销后加背景小纹样，导航苗绣红印章缩小并置于标题右下角且不碰边线。实现了纯蓝底、multiply布纹、较低亮度花鸟和同组蓝色UI表面。原花鸟滚动、导航/页脚线饰、原图与业务交互保留。
