# 展览交替留白与入场动效强化

## 目标和实现

用户反馈作品展览间距太密，要求第一行左图右文、下一行左文右图逐行交替；随绣线到达，图片从所在侧轻移淡入，文字稍晚跟上，效果更明显。开始于F:/codex_work/栏目分支合并_2026-11-07/苗绣网站的干净main/b338c07；ls-remote确认origin/main实际相同，嘉玲/aefea36已在主线历史。用户原仓库及暂存工作继续保留原样。

只改gallery.css，复用现有18件作品、交替网格和绣线/revealCard记录：展览宽度上限1120→1240px，桌面图片最大320→380px，图文网格间隔64–112→112–184px；行内上下padding由28px增至48–64px，形成96–128px行间留白。平板行间留白88px、图文间隔48px；手机保持上图下文，行间留白88px、图文间隔28px。统一普通与featured行的间距，避免局部仍拥挤。

图片由原64%不透明改为从透明入场，侧移38–64→64–104px，移动0.95秒、淡入0.8秒；文字增加淡入，延迟0.12→0.24秒，移动0.85秒/淡入0.72秒，方向与其所在栏对应。手机采用图片28px、文字24px上移。触发仍由绣线到达针结完成，滚回保持已展示；键盘聚焦立即展示、搜索和弹窗保留，减少动态偏好下静态显示。无依赖、状态逻辑、数据或图片源变化。
