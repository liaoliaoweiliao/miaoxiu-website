# 恢复小鸟浮动指引并缩小避脸

## 目标与结果

用户明确否决`8a8d94d`中把指引移到底部的方案，要求恢复做渐变之前的浮动指引，并追加要求：指引缩小、透明度降低，在指尖停靠时放到小鸟下方。

本轮恢复鸟按钮内的`heritage-bird-hint`和随鸟定位，移除底部新增的小字；字号改为桌面11px、手机10px，内距4px×8px，最大宽度由260px减到190px，按文字自然收窄。提示整体opacity为0.72、底色alpha为0.48，去除文字发光与阴影；将光晕限定在小鸟图像上。指尖阶段通过`is-at-fingertip`将提示置于鸟下方10px处；其他阶段沿用上方提示，飞行时隐藏。长卷上下边缘渐变继续保留。

新要求替代[上一轮指引方案](2026-10-21-小鸟指引弱化与避让.md)；原日志只记录当时实现，不代表当前采用方案。

## 验证

2026-10-21，Windows / 系统Edge；基线`8a8d94d`加本轮恢复，工作区另有标题字体等独立修改，按原样保全：

- `npm run build`：通过。
- `npx playwright test --grep "reflow|bird"`：7/7通过，包含五页响应式布局、三次小鸟互动、浮动提示的视口约束及指尖下置检查。
- 1440×900桌面和390×844手机视口截图确认人物面部未被提示遮挡，提示字号11px/10px，整体opacity 0.72、背景alpha 0.48。

其余E2E、离线构建与真实设备未复测。

## 恢复入口

指引标记在`HeritageJourney.jsx`的鸟按钮内，样式在`home.css`的`heritage-bird-hint`，窄屏定位约束在`responsive.css`。
