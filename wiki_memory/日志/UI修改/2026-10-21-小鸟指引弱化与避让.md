# 小鸟指引弱化与避让

## 目标与结果

用户指出随鸟移动的大胶囊比小鸟更醒目，并在指尖停靠时遮挡绣娘的脸。Agent在此要求内将操作提示收进底部阶段栏：桌面11px、手机10px，灰色常规字重，无底色、边框和发光效果；飞行时隐去并保留占位。提示与小鸟分离，面部附近只保留小鸟。按钮的无障碍名称和原三段故事交互继续使用现有状态。

## 关键改动

- `HeritageJourney.jsx` 移除鸟按钮内的浮动文字，将提示放到阶段编号旁。
- `home.css` 使用低对比度小字；移除旧胶囊样式。
- `responsive.css` 移除原260px宽提示框及定位规则；清理仅用于浮层的CSS变量。
- 更新既有响应式测试，检查三个阶段中提示在视口内且位于小鸟下方。

2026-10-21，Windows / Node v24.22.0 / npm 11.19.1 / 系统Edge；验证基线为`c0350f2`加本轮未提交改动：
