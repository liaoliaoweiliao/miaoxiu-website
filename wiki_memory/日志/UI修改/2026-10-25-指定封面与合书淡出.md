# 指定封面与合书淡出

## 要求与范围

用户提供新PNG，要求苗绣探源三本故事绘本点击右上角关闭后，从左向右合上、显示指定封面，再淡出消失，推送静涛。仅改探源绘本、相关测试/素材来源和工程记忆，不改其他栏目或桌面主进程。

## 实现

- 用户附件原样复制为public/assets/history/storybooks/closed-book-user.png，1086×1448 RGBA，SHA256为6f104124c01a59e41b443420ad4a3e12a347832f4b742cc470fbbaf273db19f7，与此前cover-book-user.png文件不同。打开仍用原图，关闭背面改用新图，React DOM preload提前加载。
- Agent选择0.8秒左页绕中缝向右翻180度，合拢时隐藏原右页。背面contain保持原比例，取消棕色矩形底和矩形阴影，保留PNG透明通道和自然阴影。
- 合拢、居中及短暂停留后，绘本本身约1.15～1.62秒淡出，遮罩最后淡出，整体1.8秒结束卸载；异常计时兜底调整为2秒。重复关闭防护、Escape/遮罩、提前关闭、滚动和焦点恢复、减少动态效果偏好保留。
- 三绘本浏览器断言新增指定封面URL、透明背景/contain、右页隐藏、先书淡出后遮罩淡出的时间采样。“阅读文字”保持已删除。
