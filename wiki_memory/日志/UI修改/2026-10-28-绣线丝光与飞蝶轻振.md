# 绣线丝光与飞蝶轻振

## 目标和结果

用户反馈上一版转换线像毛线，要求苗绣丝线感觉、不要过细或过粗，并增加点击布上蝴蝶后的轻微振翅飞行。起点静涛/a2b9821，工作区干净，实际origin/静涛相同且已fetch。

Agent将绣线芯宽从桌面4.2/手机3.2改为2.5/2.1 CSS像素，外光层宽从3.5倍收至1.6倍、强度系数0.16降至0.035。程序化片元增加细密平行纤维、微捻纹、圆润横截面和窄幅侧向高光；细线底层更克制，材质颜色更多来自源图。设计目标是紧密光滑的刺绣丝线，避免厚光晕的毛绒观感；不宣称使用真实材质扫描。6,000细线及240束64段三角带、牵引路线、三密度和五组对应应用保留。

butterflyPoint新增只在飞行阶段生效的体侧双翼铰链变换，2.2Hz、最大0.42rad，sin(π×进度)包络使首尾恢复展开。翅尖投影收拢幅度小于10%、轻微抬起；身体中心与既定直线不变。驻足仍等比，点击后先前人物/布面淡出、1.8秒飞行和GPU交接保留。减少动态直接交接，暂停/清理机制不变。

## 验证

Windows、Node24.22.0、npm11.19.1、Edge，a2b9821加本轮工作区：

- npm test 29/29通过；新增双翼轻振、左右对称、身体固定和首尾归位回归，原比例/直线飞行测试保留。
- npm run build通过（64模块）；构建后particles/site共20/20浏览器回归通过，包括五组/三密度真实GPU绘制、手势配对、取消/释放设备、首页及其他既有流程。
- 1440/390/320px绣线与飞行截图已目视核对，无溢出、页面异常或GL错误；百万档实际POINTS 1,000,000，LINES 240,000，TRIANGLES 92,160/层，跨组连接GL错误为0。截图及验收脚本仅留在忽略目录desktop-test-results/silk-wing/，临时服务与浏览器已关闭。
