# 首页第四板块边缘渐隐

## 目标

将首页小鸟长卷板块上下硬边柔化，使长卷自然过渡到共享花鸟底纹，并保留标题、互动按钮和阶段提示的可读性。

## 实现

- `src/styles/home.css` 将长卷外围和视口底色改为透明，让页面共享背景能够显露。
- 视口顶部和底部增加复用全站花鸟背景的固定背景伪元素，以 CSS 蒙版从背景渐隐至长卷；标题、底部阶段提示与小鸟绘制在渐变层上方。
- 不改动 `HeritageJourney.jsx` 的故事状态、按钮行为或素材。

## 验证

2026-10-21，代码起点为干净的 `codex/home` / `bb9770d`；Windows / Node v24.22.0 / npm 11.19.1 / 系统Edge：

- `npm run build`：通过。
- `npm run test:e2e`：28/28通过，包含小鸟三段故事与窄屏可操作检查。
- `npm run build:standalone`：通过。
- 目视检查1440×900桌面与390×844移动截图；上下边缘接入花鸟底纹，标题、按钮和阶段说明保持清晰。

未覆盖真实手机、其他浏览器、托管发布及远程CI。
