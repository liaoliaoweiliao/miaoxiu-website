# 作品展览随绣线入场

用户要求为作品展览增加动效。Agent选择沿用现有滚动绣线，在到达针结时分开呈现图片与文字。桌面和平板的图片从所在侧轻移淡入，文字延迟120ms移动，手机改用短距离上浮。复用作品入场记录，滚回时保持可读。搜索或聚焦时立即就位，减少动态偏好下静态显示。保留18件作品的交替布局、内容、图片观赏与搜索。
